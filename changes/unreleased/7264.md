## 2026-11-22 - Record the creator build in session headers (senpi#6626)

### What changed

- `packages/coding-agent/src/core/session-manager.ts` includes the running engine's build string in newly minted CLI session headers, including branches and forks.

### Why

- The header's format version cannot identify the engine that created the transcript.

### Why an extension could not handle it

- `SessionManager` writes the header before extension-owned records and also creates forked files directly.

### Expected merge conflict zones

- Header construction in `newSession`, `createBranchedSession`, and `forkFrom`.

<!-- changes-log: packages/coding-agent/CHANGELOG.md -->
### Added
- New session headers record their creator engine's build as `engineVersion`. Existing files remain readable without the field ([#7264](https://github.com/code-yeongyu/senpi/pull/7264)).
