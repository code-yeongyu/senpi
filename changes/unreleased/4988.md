## 2026-10-30 - Vitest dot output ends a line every 100 results (senpi#2291)

### What changed

- `packages/agent/vitest.config.ts`: `reporters: dotReporters()` from `scripts/vitest-dot-reporters.mjs` replaces the inline `["dot", "github-actions"]` / `["dot"]` choice. The reporter set is unchanged; the dot reporter now ends its line every 100 results off a TTY.

### Why

- senpi#2291: off a TTY, Vitest's built-in dot reporter printed the whole run on one line (532 KB for packages/ai). `gh run view --log` stops at the first line over 64 KiB, so every release log read that way ended at packages/ai's RUN banner and looked like a silent hang. The suite had passed in about 90 s.

### Why an extension could not handle it

- Test-runner configuration is not reachable from the agent's extension API.

### Expected merge conflict zones

- LOW: the `reporters` line and the import block of the listed Vitest config.
