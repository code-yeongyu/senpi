## 2026-11-22 - Avoid a false core Bash default (senpi#5345)

### What changed
- `packages/coding-agent/src/core/tools/bash-schema.ts` describes an optional timeout without claiming the runtime applies no default.

### Why
- The timeout builtin supplies a configured deadline when the caller leaves the timeout out.

### Why an extension could not handle it
- The core definition supplies the schema text independently of the extension's prompt.

### Expected merge conflict zones
- The core Bash timeout parameter.
