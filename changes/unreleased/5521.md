### Fixed
- Agent shells get exactly the session's environment on every terminal backend. A variable deleted from `process.env` under Bun, or passed as `undefined`, no longer reaches the child through the OS environment. This is how the engine trust CA closure (`SSL_CERT_FILE`/`SSL_CERT_DIR` pointing at an empty store) leaked into macOS agent shells and broke `curl`, `gh` and `git` over HTTPS ([#5521](https://github.com/code-yeongyu/senpi/pull/5521))
