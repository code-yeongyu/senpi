## 2026-11-21 - Bun 1.4.5 and every outdated dependency to latest (senpi#7161, PR #7163)

### What changed

- `packages/ai/src/api/google-generative-ai.ts`: a model without `baseUrl` sets `httpOptions.apiVersion: "v1beta"`: @google/genai 3 defaults the Gemini Developer API to `v1`, which lacks the `-latest` aliases, preview models and caches.
- `packages/ai/src/api/google-shared.ts`: `mapStopReason` maps @google/genai 3's new `FinishReason` values: `CONTINUATION` to `length`; `MISSING_THOUGHT_SIGNATURE`, `MALFORMED_RESPONSE`, `ESCALATION`, `PUP_LIMITED_DISABLED`, `MODEL_ARMOR` to `error` (they reached the exhaustive-switch throw before).
- `packages/ai/src/api/openai-images-params.ts`: imports `openai/resources/images` (ESM declarations) instead of the `.js` subpath (CJS declarations under openai 7).
- `packages/ai/src/api/openai-images-result.ts`: imports `openai/resources/images` (ESM declarations) instead of the `.js` subpath (CJS declarations under openai 7).
- `packages/ai/src/api/openai-images.ts`: edit and generate calls pass their own SDK param type instead of an intersection, and the image types import the ESM subpath `openai/resources/images`: openai 7's `.js` subpath resolves to its CJS declarations, whose upload brands differ from the ESM client's.
- `packages/ai/src/api/openai-responses-prompt-cache.ts`: `OpenAIPromptCacheOptionsPayload.comparison_response_id` is `string | null`, matching openai 7's `PromptCacheOptions`.
- `packages/ai/src/api/openai-responses-shared.ts`: the system block's `prompt_cache_breakpoint.mode` is a literal `"explicit"`, which openai 7 types require.

### Why

- Bun 1.4.5 is a security release, and the dependencies had fallen behind, including majors (openai 7, @google/genai 3, google-auth-library 11). Each change here is what the upgrade needed to keep today's behaviour. Deferred, each with its blocker: @anthropic-ai/sdk 1.x (senpi#7162), vitest 5.1 on Bun (senpi#7164), signal-exit 4 (senpi#7165), oxc-parser 0.159 (senpi#7166), and releases still inside `min-release-age` (senpi#7167).
