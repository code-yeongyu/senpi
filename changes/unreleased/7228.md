## 2026-11-22 - Presenter frames are advertised only when served (senpi#5782)

### What changed

- `packages/coding-agent/src/modes/interactive/session-control-commands.ts`: `get_protocol_info` lists the MCP presenter frames (`mcp_presenter_context`, `mcp_form_presented`, `mcp_form_response`, `mcp_form_sync`, `mcp_presenter_secret_answer`) only when the endpoint has a presenter surface; every other command is unchanged.

### Why

- A terminal endpoint without a presenter surface advertised the frames and then answered them `unsupported`, so a client that trusted `commands` sent frames it could not use.

### Why an extension could not handle it

- The terminal control endpoint's protocol answer is built in core; an extension cannot change the advertised command list.

### Expected merge conflict zones

- LOW: the `TUI_CONTROL_COMMANDS` list and the `get_protocol_info` case in `session-control-commands.ts` (fork-only file).
