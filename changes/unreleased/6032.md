### Fixed
- A resumed or moved brain no longer runs a remote tool call or a loop hook twice (senpi#5867). A remote call's execution id is now `remoteExecutionId(scope, turn, toolCallId)`, built only from durable turn state (`ToolHostCall.turn`, the issuing assistant message's identity), so every dispatch of that call by any brain instance carries the same id and the hand answers a repeat from its record. `LoopHookHost.run(event, payload, signal, callKey)` takes a durable key (`loopHookCallKey(session, turn, event, ordinal)`), so a new loop host re-issues a pending hook under the same id: a settled hook is answered from the hand's stored answer and a started one is joined. `close()` rejects with the new `LoopHookClosedError`.

## 2026-11-05 - Durable remote call and loop-hook call ids (senpi#5867)

### What changed

- `packages/agent/src/execution/tool-host.ts`: `ToolHostCall` carries an optional durable `turn` key.
- `packages/agent/src/agent-loop.ts`: each tool batch passes `turn` (the assistant message's `timestamp:responseId`).
- `packages/agent/src/execution/remote-tool-host.ts`: `remoteExecutionId(scope, turn, toolCallId)` replaces the per-dispatch random id for turn-bound calls; `mintId` stays for device-file operations.
- `packages/agent/src/execution/loop-hook-host.ts`: `loopHookCallKey`, an optional `callKey` on `run`, and `LoopHookClosedError` on close.
- `packages/agent/src/execution/testing/hand-harness.ts`, `testing/epoch-harness.ts`: the harnesses dispatch with a turn and can replace the brain with a fresh instance.
- `packages/agent/src/index.ts`: exports `remoteExecutionId`, `loopHookCallKey` and `LoopHookClosedError`.

### Why

The brain minted a new random id per dispatch, so a restarted or moved brain re-dispatching the same call reached the hand as a new call and ran it again (senpi#5867, found by the session-move and hosted-hooks design reviews).

### Why an extension could not handle it

The id is minted inside the agent loop's dispatch and the loop-hook link, before any extension sees the call.

### Expected merge conflict zones

`agent-loop.ts` tool batch dispatch; `remote-tool-host.ts` invoke construction; `loop-hook-host.ts` `run` and `close`; `src/index.ts` exports.
