## 2026-11-22 - Responses cache affinity honors the marked prompt prefix (senpi#5127)

### What changed

- `packages/ai/src/api/openai-prompt-cache.ts` uses the marked stable system text when deriving the cache key. Unmarked prompts keep their existing key.

### Why

- Volatile instructions after a shared prefix should reach the model without splitting otherwise identical cache keys.

### Why an extension could not handle it

- The Responses adapters derive the key after transcript normalization; the outgoing instructions and tool schemas are unchanged.

### Expected merge conflict zones

- LOW: the system-text input to the existing v1 hash in `packages/ai/src/api/openai-prompt-cache.ts`.
