## 2026-11-22 - The eval routing rule names the tool for source edits (#7275, senpi#7232)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/prompt-preset/execution-tooling.ts`: `eval-routing-decision` sends source edits to the `edit` / `write` tool, not cell code, in every wording (claude short, claude full, kimi); side effects, deploys, approvals and calls fed by an unseen result still run one at a time. `eval-stay-direct` drops "the result decides the next call", which the routing rule already covers. The header carries a dated note.
- Size (characters, both rules together): claude short -2, kimi -1, claude full -8. Per rule: routing +24 / +40 / +26, stay-direct -26 / -41 / -34 (claude short / kimi / claude full).
- `test/suite/prompt-presets-native-baseline.json`: the 54 eval-selected rows (`:terminal:1`, `:app:1`, `:chat:1`) of the 18 presets that render the section are recaptured: claude-fable-5, claude-fable-5-1, claude-fable-5-2, claude-opus-5-5, claude-opus-5, claude-sonnet-5-5, claude-haiku-5-5, claude-opus-4-{8,7,6,5}, glm-5.2, glm-5.3, kimi-k3, kimi-k3-1, kimi-k2-{8,7,6}. `sourceCommit` is unchanged.
- `test/suite/prompt-presets-shared-sections.test.ts`: the 30 `PRESET_ROWS` eval-selected hashes (claude-fable-5, -5-1, -5-2, claude-opus-5-5, claude-opus-5, claude-opus-4-{8,7,6,5}, glm-5.3) and the 12 `REQUEST_ROWS` eval variants (`eval-true`, `app-eval-true`, `search-eval-true` of claude-opus-5.5, claude-fable-5.1, claude-opus-4-7, glm-5.3) are recaptured. No row without eval changes, and no GPT, DeepSeek, Grok, Gemini or default row changes.

### Why

- senpi#7232, diagnosis category B (misframing): in a multi-harness build comparison, agents wrote their source files from eval cells (34 file writes in one run, every file in another). "Edits ... one at a time" gave a cadence and no destination, so one write per cell satisfied it.

### Why an extension could not handle it

- The shared execution-tooling rules are this builtin's own data.

### Expected merge conflict zones

- LOW: the `eval-routing-decision` and `eval-stay-direct` entries of `EXECUTION_TOOLING_RULES`, and the hash rows above in the two test files.
