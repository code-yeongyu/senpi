## 2026-11-24 - Install telemetry honors DO_NOT_TRACK and OMO_DISABLE_TELEMETRY (oh-my-openagent#14920)

### What changed

- `packages/coding-agent/src/core/telemetry.ts`: `isInstallTelemetryEnabled` takes an optional `env` (default `process.env`) and returns `false` when `DO_NOT_TRACK` or `OMO_DISABLE_TELEMETRY` is truthy (`1`/`true`/`yes`), before the brand `TELEMETRY` env and the `enableInstallTelemetry` setting are consulted.

### Why

- One opt-out must stop every sender (oh-my-openagent#14920): the install ping and the provider attribution headers ignored the two machine-wide switches every omo product honors, so a user who opted out machine-wide was still pinged by standalone senpi.

### Why an extension could not handle it

- The gate is read inside `interactive-mode.ts` and `provider-attribution.ts` before any extension point runs; an extension cannot remove a header the core send path adds.

### Expected merge conflict zones

- LOW: `core/telemetry.ts` is small and additive; a conflict only arises if upstream changes `isInstallTelemetryEnabled`'s signature in the same window.
