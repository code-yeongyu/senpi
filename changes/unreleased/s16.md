## RPC compact stream materialization (part of #4272)

- Behind the disabled-by-default compact socket flag, required streams include initial, later, pending and active mirrors without attachment holds. Filtered transitions repair state from a pre-record cut inside the next dependent delivery unit.
- Selected compact records use bounded per-admission envelopes over one shared immutable event payload. Atomic units are not demoted into separate delta/control frames. Mirror reset uses the existing admission and stream generation owners.
- Existing legacy routing and the attachment authorization gate remain in place.
- `@earendil-works/pi-client` adds a transaction-bound materializer consumer and adapter contract, plus a reference in-memory adapter and a bounded envelope parser. S15a frames still parse unchanged. Its `./materializer-test-kit` export is the conformance suite that desktop adapters run unchanged.
