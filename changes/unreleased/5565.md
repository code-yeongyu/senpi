## 2026-11-03 - Resume admission accepts a registered compaction owner when compaction is disabled (senpi#3121)

### What changed

- `packages/coding-agent/src/core/sdk.ts`: the resume admission catch no longer rethrows `ModelUsabilityBudgetError` when compaction is disabled but `session.hasCompactionOwner()` is true; the session is admitted through the existing resume slice or `admitResumeCompactionRequired()` path.
- `packages/coding-agent/src/core/agent-session.ts`: new public `hasCompactionOwner()`, true when a non-builtin extension registered `session_before_compact` (the builtin compaction and hooks handlers are always registered, so they are excluded through `isBuiltinExtensionPath`).

### Why

- `packages/coding-agent/src/core/sdk.ts`: with `compaction.enabled: false` and an extension that owns compaction, an over-budget session could never be resumed although the owner could compact it on the first prompt; the recorded requirement already drains through pre-prompt compaction, which reaches `session_before_compact`.
- `packages/coding-agent/src/core/agent-session.ts`: the admission needs one predicate for "an extension owns compaction" that ignores always-present builtin handlers.

### Why an extension could not handle it

- `packages/coding-agent/src/core/sdk.ts`: resume admission runs inside `createAgentSession` before any extension is bound; an extension cannot reach or override the refusal.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/sdk.ts` the `getCompactionEnabled()` condition in the resume admission catch; `packages/coding-agent/src/core/agent-session.ts` the new method after `hasExtensionHandlers()`.

## 2026-11-03 - ExtensionRunner.getHandlerExtensionPaths (senpi#3121)

### What changed

- `packages/coding-agent/src/core/extensions/runner.ts`: new `getHandlerExtensionPaths(eventType)` returns the paths of the extensions that registered a handler for an event, in load order.

### Why

- `packages/coding-agent/src/core/extensions/runner.ts`: resume admission must tell a user's compaction owner apart from the builtin `session_before_compact` handlers, which `hasHandlers()` cannot do.

### Why an extension could not handle it

- `packages/coding-agent/src/core/extensions/runner.ts`: the handler registry is private runner state.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/extensions/runner.ts` next to `hasHandlers()`.
