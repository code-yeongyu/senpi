## 2026-11-12 - Title retry recognises a non-English thinking-off refusal (senpi#6548)

### What changed
- `packages/coding-agent/src/core/session-title-reasoning.ts`: `REASONING_MANDATORY_ERROR` also matches the always-thinking refusal a gateway model returns in Chinese ("始终思考" / "不支持关闭思考"), so `mandatoryReasoningRetryLevel` retries the title with `low` reasoning instead of failing.

### Why
- The title is asked for with thinking off when the catalog says the model can turn it off; an always-thinking model behind a gateway refused that request in Chinese, which the English-only pattern missed, so the title request failed in the session's first minute (#6548).

### Why an extension could not handle it
- Title generation is engine code.

### Expected merge conflict zones
- The `REASONING_MANDATORY_ERROR` constant in `session-title-reasoning.ts`.
