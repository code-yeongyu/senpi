## 2026-11-12 - Long-session animation has a separate presentation cadence (senpi#6537)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: use cached status content with independent working and hook label animation.
- `packages/coding-agent/src/modes/interactive/working-status.ts`: export the existing message-frame style type for the presentation helper.
- `packages/coding-agent/src/modes/interactive/working-status-animation.ts`: cache elapsed/status suffixes at the existing content cadence.
- `packages/coding-agent/src/modes/interactive/components/animation-frame.ts` and `packages/coding-agent/src/modes/interactive/components/animated-status-text.ts`: request the next frame only while a component is painted.
- `packages/coding-agent/src/modes/interactive/components/exploration-group.ts` and `packages/coding-agent/src/modes/interactive/components/exploration-transcript-container.ts`: pending groups request frames independently and cancel them on completion, removal, clearing, detachment or disposal.

### Why

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts` previously used the long-session one-second content interval for label animation too; `packages/coding-agent/src/modes/interactive/working-status.ts` keeps that content throttle.
- `packages/coding-agent/src/modes/interactive/working-status-animation.ts`, `packages/coding-agent/src/modes/interactive/components/animation-frame.ts` and `packages/coding-agent/src/modes/interactive/components/animated-status-text.ts` separate visual frames from status rebuilding.
- `packages/coding-agent/src/modes/interactive/components/exploration-group.ts` sampled an 80 ms spinner only when rendered; `packages/coding-agent/src/modes/interactive/components/exploration-transcript-container.ts` owns its projected groups' animation lifetime.

### Why an extension could not handle it

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts` and `packages/coding-agent/src/modes/interactive/working-status.ts` own the default status cadence and styling.
- `packages/coding-agent/src/modes/interactive/working-status-animation.ts`, `packages/coding-agent/src/modes/interactive/components/animation-frame.ts` and `packages/coding-agent/src/modes/interactive/components/animated-status-text.ts` run inside that core presentation path.
- `packages/coding-agent/src/modes/interactive/components/exploration-group.ts` and `packages/coding-agent/src/modes/interactive/components/exploration-transcript-container.ts` manage core transcript projections; extensions do not own their redraw or disposal boundaries.

### Expected merge conflict zones

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: working indicator construction and hook status row construction.
- `packages/coding-agent/src/modes/interactive/working-status.ts` and `packages/coding-agent/src/modes/interactive/working-status-animation.ts`: shared style type and status formatting.
- `packages/coding-agent/src/modes/interactive/components/animation-frame.ts` and `packages/coding-agent/src/modes/interactive/components/animated-status-text.ts`: animation scheduling and disposal.
- `packages/coding-agent/src/modes/interactive/components/exploration-group.ts` and `packages/coding-agent/src/modes/interactive/components/exploration-transcript-container.ts`: pending-group rendering and projection lifecycle.

## 2026-11-12 - Loader can animate cached message presentation (senpi#6537)

### What changed

- `packages/tui/src/components/loader.ts`: add optional presentation formatter/interval options, reuse an existing timer when its cadence matches, and stop the independent presentation timer with the loader.

### Why

- `packages/tui/src/components/loader.ts`: long-session status colors must move between slower message-content updates without speeding up decorative frames or rebuilding status content.

### Why an extension could not handle it

- `packages/tui/src/components/loader.ts`: the loader owns its message cache, decorative frames and timer lifecycle; a caller needs a presentation callback at that boundary.

### Expected merge conflict zones

- `packages/tui/src/components/loader.ts`: indicator options, timer restart/stop, and display composition. Existing callers without presentation options retain their previous behavior.
