## 2026-11-22 - The root type check refuses an older Bun instead of recursing (senpi#4783)

### What changed

- `package.json`: the `check` script type-checks through `node scripts/bun-check.mjs` instead of bare `bun check --no-script`.
- `scripts/bun-builtin.mjs`: one Bun >= 1.4.4 probe and runner for the `bun fmt` and `bun check` builtins; `scripts/bun-fmt.mjs` and the new `scripts/bun-check.mjs` wrap it.

### Why

- A Bun older than 1.4.4 resolves `bun check` to the package's own `check` script, which re-enters itself forever.

### Why an extension could not handle it

- Root package scripts and repository tooling are outside the extension surface.

### Expected merge conflict zones

- LOW: the root `check` script in `package.json`.
