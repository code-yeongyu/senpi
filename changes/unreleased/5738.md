## 2026-11-04 - Prepared executor and batch host in the agent package (senpi#5738)

### What changed

- `packages/agent/src/execution/prepared/` is new: the prepared executor and the prepared batch host, moved from `packages/coding-agent/src/core/execution/`. A loop with no execution scope (an empty workspace root) now admits its per-batch ledger under a fixed in-process workspace name.
- `packages/agent/src/execution/canonical-digest.ts` is new: the one canonical JSON and Web Crypto SHA-256 every execution digest hashes.
- `packages/agent/src/execution/coordinator-plan.ts`: the manifest digest uses `canonical-digest.ts` instead of its own copy.
- `packages/agent/src/index.ts`: exports `createPreparedToolHost`, `canonicalJson` and `toStoreValue`.

### Why

Plan row S36: the legacy scheduler in `agent-loop.ts` can only be removed once the loop's own package carries the pipeline that replaces it. The executor needed only agent-core, and a browser-safe digest keeps `node:crypto` out of the core.

### Why an extension could not handle it

The loop's default tool execution is the agent package's own contract.

### Expected merge conflict zones

`src/index.ts` exports; `coordinator-plan.ts` digest helpers.

## 2026-11-04 - The prepared pipeline comes from the agent package (senpi#5738)

### What changed

- `packages/coding-agent/src/core/execution/executor*.ts`, `pipeline-prepared.ts` and `pipeline-prepared-batch.ts` moved to `packages/agent/src/execution/prepared/`.
- `packages/coding-agent/src/core/execution/pipeline-witness.ts`: now holds `requestedExecutionPipeline` (the `SENPI_EXECUTION_PIPELINE` parse) and imports `createPreparedToolHost` from agent-core.
- `packages/coding-agent/src/core/execution/catalog-digest.ts`: hashes agent-core's `canonicalJson` with `node:crypto`, the same bytes as before.

### Why

Plan row S36 (senpi#5728): the prepared pipeline moves into the agent package so the loop can use it as its default.

### Why an extension could not handle it

The session's ToolHost and receipt sink are bound by the session itself.

### Expected merge conflict zones

`pipeline-witness.ts`; `catalog-digest.ts`.
