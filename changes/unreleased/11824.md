## 2026-10-29 - Retain only the latest streaming partial (part of #2929)

### What changed

- `packages/coding-agent/src/modes/rpc/session-event-fanout.ts` demotes superseded replay snapshots; only the latest update retains cumulative `message` / `partial` fields. Completion and abort release replay state.
- `packages/coding-agent/src/modes/rpc/rpc-client.ts` demotes collected and pending-open snapshots without mutating live events.
- `packages/coding-agent/src/modes/rpc/session-event-writer.ts` demotes queued snapshots across ordering barriers and non-delta updates while preserving every delta.
- `packages/coding-agent/src/modes/rpc/demote-message-update.ts` preserves deltas, metadata, and tool-call start identity when releasing cumulative fields.
- `packages/coding-agent/src/modes/rpc/event-output-buffer.ts` releases superseded same-tick snapshots through the existing classic JSON projection; `packages/coding-agent/src/modes/rpc/rpc-mode.ts` accepts those already projected records.

### Why

- The terminal control endpoint feeds replay even without attached clients. Retaining every serialized cumulative partial held quadratic bytes until message end (omo#11824). The idle feed remains necessary for late attachment and now holds delta history plus one current partial.

### Why an extension could not handle it

- These buffers belong to the RPC transport and terminal control endpoint below extension delivery.

### Expected merge conflict zones

- `packages/coding-agent/src/modes/rpc/session-event-fanout.ts` overlaps #4530 and #4534; `packages/coding-agent/src/modes/rpc/session-event-writer.ts` overlaps #4530. This fix preserves the current-main legacy wire contract and does not enable the compact-state rollout.
- `packages/coding-agent/src/modes/rpc/rpc-client.ts`, `packages/coding-agent/src/modes/rpc/event-output-buffer.ts`, `packages/coding-agent/src/modes/rpc/rpc-mode.ts`, and `packages/coding-agent/src/modes/rpc/demote-message-update.ts`: snapshot demotion only, with unchanged final messages and delta ordering.
