## 2026-11-25 - Gemini MALFORMED_RESPONSE is an error stop, not an unhandled one (senpi#7437, senpi#7436)

### What changed

- `packages/ai/src/api/google-shared.ts`: `mapStopReason` returns `"error"` for the finish reason `MALFORMED_RESPONSE`, checked on the string before the `switch` over the SDK `FinishReason` enum. The Google Generative AI and Vertex adapters now report it as `Provider stopped with: MALFORMED_RESPONSE`, like `MALFORMED_FUNCTION_CALL`, instead of throwing `Unhandled stop reason: MALFORMED_RESPONSE`.

### Why

- senpi#7436. The Gemini API returns `MALFORMED_RESPONSE` for a generation that produced no content, but the `@google/genai` `FinishReason` enum does not list it (googleapis/python-genai#2937), so the exhaustive `switch` fell to its `default` branch and threw. The turn failed with an error the retry classifier does not recognise.

### Why an extension could not handle it

- The mapping runs inside the shared Google stream consumer while the stream is read; the throw happens before any extension hook sees the message.

### Expected merge conflict zones

- LOW: the first line of `mapStopReason`. Upstream's `switch` is unchanged; if the SDK enum gains `MALFORMED_RESPONSE`, the `never` check in the `switch` flags the extra line, which can then be removed.

## 2026-11-25 - Gemini MALFORMED_RESPONSE is retried (senpi#7437, senpi#7436)

### What changed

- `packages/ai/src/utils/retry.ts`: `Provider stopped with: MALFORMED_RESPONSE` is added to the retryable provider error patterns. `Provider stopped with: MALFORMED_FUNCTION_CALL` stays non-retryable.

### Why

- senpi#7436. `MALFORMED_RESPONSE` is an intermittent server-side failure; the same request usually succeeds on the next attempt, and in observed cases the message carries no content. The text only comes from the two Google adapters, so the pattern does not widen the classifier for other providers.

### Why an extension could not handle it

- The classifier is a module-level pattern list used by the agent loop and the turn retry; no extension hook can contribute patterns to it.

### Expected merge conflict zones

- LOW: one added entry next to `Credential store is busy: lock` in `RETRYABLE_PROVIDER_ERROR_PATTERN`.
