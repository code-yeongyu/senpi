## 2026-11-11 - Thinking-level changes leave the transcript in place (doriterm#2101)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: `thinking_level_changed` updates the footer and editor border without adding a "Thinking level" chat row. The session still persists and emits the thinking-level change.

### Why

- Adding a status row and spacer moved the startup transcript when Shift+Tab changed effort. The footer already displays the selected effort and shortcut.

### Why an extension could not handle it

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the built-in session-event handler owns the transcript notice.

- LOW: the `thinking_level_changed` case in `packages/coding-agent/src/modes/interactive/interactive-mode.ts`.
