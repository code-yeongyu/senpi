## 2026-11-26 - Forward the session ID during compaction (senpi#3406)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/compaction/speculative-summary.ts`: Pass the active session ID to the summarization stream when it is available.

### Why

Compaction requests to OpenCode Go need the session ID for the `x-opencode-session` routing header.

### Why an extension could not handle it

The built-in compaction path creates the summarization stream and its request options internally.

### Expected merge conflict zones

- LOW: The summarization stream options in `packages/coding-agent/src/core/extensions/builtin/compaction/speculative-summary.ts`.

## 2026-11-26 - Supply a session ID for standalone OpenCode streams (senpi#3406)

### What changed

- `packages/coding-agent/src/core/provider-attribution.ts`: Generate a session ID for OpenCode attribution headers when no session ID is supplied and `crypto.randomUUID` is available.

### Why

Helper streams without a session manager also need a routing header for OpenCode Go.

### Why an extension could not handle it

Provider attribution headers are assembled inside the coding-agent request path.

### Expected merge conflict zones

- LOW: The OpenCode session-header logic in `packages/coding-agent/src/core/provider-attribution.ts`.
