## 2026-11-01 - Recognize terminal-formatted Claude login output (senpi#5357)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/claude-cli-auth.ts` strips terminal control sequences before extracting the fallback URL or checking success. Its anchored success pattern accepts the exact optional paste-prompt prefix and CRLF, while still requiring exit code 0.
- The existing CLI login tests and subprocess fixture cover inline success, colored CRLF output, OSC-8 fallback links, code submission, and a nonzero exit containing the success message.

### Why

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/claude-cli-auth.ts` rejected a successful native login when `Login successful.` followed the paste prompt on the same line. The caller then rolled back that login. OSC-8 links also prevented fallback URL detection.

### Why an extension could not handle it

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/claude-cli-auth.ts` is the builtin provider's subprocess-output boundary, shared by browser and copy-code login. A separate extension cannot correct its completion result.

### Expected merge conflict zones

- LOW: the imports, success pattern, stdout handler, and close handler in `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/claude-cli-auth.ts`.
