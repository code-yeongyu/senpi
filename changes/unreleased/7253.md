## 2026-11-22 - Guard harness skill walks against ancestor links (senpi#5102)

### What changed

- `packages/agent/src/harness/skills.ts`: `loadSkillsFromDirInternal` resolves each directory through `env.canonicalPath` and returns early when that canonical path is already an ancestor on the walk stack, mirroring the coding-agent walkers. A linked folder pointing back up the tree no longer recurses until the path limit and no longer loads its skills once per level.

### Why

- `packages/agent/src/harness/skills.ts`: the harness walker followed linked directories with no canonical-path ancestry guard, unlike `packages/coding-agent/src/core/skills.ts` and `skill-discovery.ts`; a self-parent link (`skills/loop -> skills`) re-entered the same tree until the walk hit its depth bound (41 duplicate loads of the same skill in the regression test).

### Why an extension could not handle it

- `packages/agent/src/harness/skills.ts`: the walker is core skill discovery in the agent harness; extensions only observe skills after loading.

### Expected merge conflict zones

- `packages/agent/src/harness/skills.ts`: `loadSkillsFromDirInternal` signature, the directory guard after the directory-kind check, and the recursion call site.
