## 2026-10-28 - The internal key sentinel's name lives in its own leaf module (senpi#4528)

### What changed

- `packages/coding-agent/src/modes/rpc/internal-key-env.ts`: new leaf exporting `INTERNAL_KEY_STDIN_ENV` ("SENPI_RPC_INTERNAL_KEY_STDIN") and nothing else.
- `packages/coding-agent/src/modes/rpc/internal-bootstrap.ts`: imports that name instead of declaring it. No behavior change.

### Why

- `internal-bootstrap.ts` CONSUMES the variable at module load: importing it performs the stdin read and arms a deadline that SIGKILLs the importer. Anything that only needs to recognise - or drop - the name could not import it safely; a test helper that did was killed mid-run. The name now has a side-effect-free home.

### Why an extension could not handle it

- The sentinel is part of the supervisor-to-host hand-off inside the engine's RPC lane; no extension surface exposes it.

### Expected merge conflict zones

- LOW: the import block at the top of `internal-bootstrap.ts`.
