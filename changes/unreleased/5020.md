### Added

- Durable core: an inert JSONL session importer (`src/core/session-import/`) that imports a session file into a claimed durable store keyed by session ID, imports later tails exactly once, keeps a per-file ledger (size, mtime, high-water entry and hash, writer kind), forks a divergent developer-hatch rewrite marked by a `.k9f2` file, adopts every other edit in place, and commits each session with its ledger atomically. Nothing calls it yet; default-store wiring follows in later work ([#5020](https://github.com/code-yeongyu/senpi/pull/5020), part of [#4995](https://github.com/code-yeongyu/senpi/issues/4995)).
