## 2026-11-03 - Title and compaction requests select pooled credentials (senpi#5547)

### What changed

- `packages/coding-agent/src/core/agent-session.ts`: `_resolveSummarizationRequestAuth` returns no explicit key when no runtime API key is active and the runtime selects this provider's credential per request, so session title and compaction requests take the same credential selection as the main turn.
- `packages/coding-agent/src/core/model-registry.ts`: `getApiKeyAndHeaders` marks such a result `rotatesCredentials: true`; the resolved key there only proves that credentials exist.
- `packages/coding-agent/src/core/model-runtime.ts`: public `rotatesCredentials(model)`, the keyless form of `couldRotateCredentials`.

### Why

- `packages/coding-agent/src/core/agent-session.ts`: the pre-resolved stored top-level key disabled rotation (`couldRotateCredentials` refuses an explicit key), so titles and compaction ignored a pinned account and never failed over from an exhausted one (senpi#1814, senpi#1556).
- `packages/coding-agent/src/core/model-registry.ts`: the builtin compaction extension resolves auth through this facade and sent the same pinning key.
- `packages/coding-agent/src/core/model-runtime.ts`: the session and the facade need the runtime's own answer to whether a keyless request rotates.

### Why an extension could not handle it

- `packages/coding-agent/src/core/agent-session.ts`: summarization auth is resolved in core before any extension hook sees the request.
- `packages/coding-agent/src/core/model-registry.ts`: the compaction extension can only learn that a provider rotates from the registry's resolved auth.
- `packages/coding-agent/src/core/model-runtime.ts`: rotation eligibility is private runtime state.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/agent-session.ts` at the top of `_resolveSummarizationRequestAuth`.
- LOW: `packages/coding-agent/src/core/model-registry.ts` in `ResolvedRequestAuth` and the success branch of `getApiKeyAndHeaders`.
- LOW: `packages/coding-agent/src/core/model-runtime.ts` just above `couldRotateCredentials`.
