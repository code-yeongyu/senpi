### Fixed

- `/mcp reconnect` on an OAuth server whose refresh token was rotated away now always reports `needs_auth` with the `/mcp auth-start <server>` guidance. It no longer returns quietly when a credentials re-key retired the connection mid-reconnect, and no longer reports a bare `Unauthorized` when another refresh had already cleared the saved sign-in ([#7498](https://github.com/code-yeongyu/senpi/pull/7498), fixes [#6538](https://github.com/code-yeongyu/senpi/issues/6538))
