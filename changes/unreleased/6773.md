## 2026-11-15 - sessionBound means the session's record or a loop-owned store; a missing part refuses typed (senpi#6749)

### What changed

- `packages/coding-agent/src/core/extensions/types.ts`: the `ToolDefinition.sessionBound` doc states the rule. A tool is session-bound when it needs the calling session's RECORD (entries, active tools, system prompt options, loop state, placement) or a session-scoped store the loop owns (goal, `/loop`, scheduled prompts). The session's IDENTITY rides every call and binds nothing. A tool tied to the session only by device-local state keyed by its id, or by a later wake, stays unbound; this covers the terminal's background `bash` and `monitor`.
- `packages/coding-agent/src/core/extensions/runner.ts`: a loop-side member on a runtime without a session throws `SessionUnavailableError` with code `loop_side_unavailable`. The message is unchanged.
- `packages/coding-agent/src/core/extensions/builtin/terminal/rpc-monitor-targets.ts`, `tools/monitor-rpc.ts`, `tools/monitor.ts`: a `children` watch reads the identity its call carries. Without one it refuses with `session_identity_unavailable` instead of a message.
- `packages/coding-agent/src/core/extensions/builtin/loop/index.ts`: `schedule_wakeup` on a runtime where no session started refuses with `session_record_unavailable` (the loop state was never loaded) instead of "no active /loop".

### Why

- Review of #6773: `monitor`'s children branch needs the session's identity. The probe listed 10 of the 31 served tools. The classifier matched V8 TypeError wording.

### Why an extension could not handle it

- The refusals come from the runner, the carried-session accessor and builtins' own guards.

### Expected merge conflict zones

- LOW: `loopSideUnbound` in `runner.ts`; `parseRpcTarget`'s children branch; the `sessionBound` doc comment.

## 2026-11-15 - One typed error for a missing session record, identity or loop-side fact (senpi#6749)

### What changed

- `packages/coding-agent/src/core/session-unavailable.ts` (new): `SessionUnavailableError` with code `session_record_unavailable`, `session_identity_unavailable` or `loop_side_unavailable`, plus the member that was reached for.
