## 2026-11-09 - The sqlite-bun package carries the complete bun:sqlite declaration (senpi#6255)

### What changed

- `packages/session-backends/sqlite-bun/src/bun-sqlite.d.ts`: the `bun:sqlite` `Database` class is now declared here, exactly once, with the full surface the workspace uses (constructor, `exec`/`close`, `query`, `transaction`); the file previously only merged in the query/transaction members.
- `packages/session-backends/sqlite-bun/src/index.ts`: references `./bun-sqlite.d.ts` so the ambient declaration ships with the package entry point and a standalone consumer type-checks an import of the package.

### Why

- The class lived in `packages/coding-agent/src/modes/rpc/bun-sqlite.d.ts`, which is not part of the published tarball, so a temp project installing only the packed tarball (+ TypeScript) failed with `TS2307: Cannot find module 'bun:sqlite'` from the package's own sources (senpi#5996).

### Why an extension could not handle it

- The declaration is a compile-time property of the published package's own sources; no extension event sees it.

### Expected merge conflict zones

- LOW: `bun-sqlite.d.ts` (the single `bun:sqlite` declaration) and the `/// <reference>` line in `src/index.ts`.

## 2026-11-09 - The bun:sqlite declaration moves out of coding-agent (senpi#6255)

### What changed

- `packages/coding-agent/src/modes/rpc/bun-sqlite.d.ts` (deleted): the `Database` class declaration moved to `packages/session-backends/sqlite-bun/src/bun-sqlite.d.ts`, the single source for the workspace's `bun:sqlite` declaration. `packages/coding-agent/src/modes/rpc/ownership-safe-lock.ts` still resolves `bun:sqlite` through the shared file; no other file referenced the deleted path.

### Why

- The class was declared in the wrong package: a standalone consumer of the sqlite-bun package never loaded this file, so the package did not type-check on its own (senpi#5996).

### Why an extension could not handle it

- The declaration is a compile-time property of the packages' own sources; no extension event sees it.

### Expected merge conflict zones

- LOW: `ownership-safe-lock.ts` (the only coding-agent value user of `bun:sqlite`).
