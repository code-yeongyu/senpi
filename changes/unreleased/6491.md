## 2026-11-12 - Skill roots split Windows paths, and the catalog caps are configurable (senpi#4569)

### What changed

- `packages/coding-agent/src/core/skills-prompt.ts`: the roots table and each location split `skill.filePath` on `/` only, so a Windows path with backslashes produced one empty `rN` root and a full absolute location per skill. Splitting now normalizes either separator; the root keeps its host separators for `pinnedDisplayPath` and renders POSIX-shaped. New `SkillCatalogLimits` (`compactSkillCount`, `compactDescriptionBytes`, `maxBytes`) overrides the fixed caps, and `formatSkillsForPrompt`, `isLargeSkillCatalog` and `warnIfLargeSkillCatalog` accept them.
- `packages/coding-agent/src/core/dynamic-prompt/workstation.ts`: `pinnedDisplayPath` built its prefix with `path.sep`, so a POSIX-shaped `repoRoot` pin never matched on Windows. It matches either separator now and preserves the remainder.
- `packages/coding-agent/src/core/settings-manager.ts`: `Settings.skillCatalog`.
- `packages/coding-agent/src/core/agent-session.ts`: the prompt options carry `skillCatalog` from settings.
- `packages/coding-agent/src/core/resource-loader.ts`: the catalog size warning resolves the same limits.
- `packages/coding-agent/src/core/system-prompt.ts` and `packages/coding-agent/src/core/dynamic-prompt/build.ts`: pass the limits to `formatSkillsForPrompt`.
- `packages/coding-agent/docs/settings.md`: the three settings and the configurable paragraph.

### Why

- On Windows every skill rendered as one rootless absolute path, which defeated the roots table and inflated each request; the subscription lane's root rewrite also could not match (senpi#4569 item 2).
- The caps were fixed constants, so a user could only shrink the catalog by removing skills (senpi#3460).

### Why an extension could not handle it

- The catalog is rendered into every system prompt by core, before any extension sees it, and the roots table is built from `Skill.filePath` inside the formatter.

### Expected merge conflict zones

- LOW: `skillRootPath`/`skillRelativePath`/`skillRootDisplayPath` and the roots loop in `skills-prompt.ts`; the `pinnedDisplayPath` tail in `workstation.ts`; one option line in `agent-session.ts`, `system-prompt.ts` and `build.ts`; one settings field.

### Fixed
- Skill roots and locations split Windows paths on both separators, so a Windows host no longer renders one empty root and a full absolute path per skill (senpi#4569).
- The skills catalog caps are configurable per session through `skillCatalog.compactSkillCount`, `compactDescriptionBytes` and `maxBytes`.
