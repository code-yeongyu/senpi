## 2026-10-30 - Serialize rotating-token refresh per session (senpi#5003, PR #5024)

### What changed

- `packages/ai/src/auth/types.ts` adds the optional `CredentialStore.withRefreshLock` capability. `packages/ai/src/auth/oauth-refresh.ts` holds it across read-latest, exchange and persistence, sharing a stable provider/slot identity between flat, named-slot and catalog refreshes.

### Why

- `packages/ai/src/auth/types.ts` and `packages/ai/src/auth/oauth-refresh.ts` previously provided only process-local exchange deduplication. Compare-and-swap after exchange cannot prevent two processes from consuming one rotating refresh token. The global write lock stays outside the exchange as required by #1542.

### Why an extension could not handle it

- `packages/ai/src/auth/types.ts` and `packages/ai/src/auth/oauth-refresh.ts` define the credential-store contract and common refresh path below extension hooks.

### Expected merge conflict zones

- `packages/ai/src/auth/types.ts`: credential-store capability. `packages/ai/src/auth/oauth-refresh.ts`: pre-exchange read and dispatch.

## 2026-10-30 - Inject file-backed session refresh locks (senpi#5003)

### What changed

- `packages/coding-agent/src/core/auth-storage.ts` implements per-provider/slot file locks, strictly reloads credentials after acquisition, and retains short global write locks. `packages/coding-agent/src/core/runtime-credentials.ts` forwards the capability.

### Why

- `packages/coding-agent/src/core/auth-storage.ts` must serialize rotating refresh exchanges across processes without blocking unrelated accounts. `packages/coding-agent/src/core/runtime-credentials.ts` is the production overlay and must preserve that exclusion.

### Why an extension could not handle it

- `packages/coding-agent/src/core/auth-storage.ts` owns the persistent store and file locks; `packages/coding-agent/src/core/runtime-credentials.ts` owns the store overlay below extensions.

### Expected merge conflict zones

- `packages/coding-agent/src/core/auth-storage.ts`: lock acquisition and constructor. `packages/coding-agent/src/core/runtime-credentials.ts`: constructor forwarding.
