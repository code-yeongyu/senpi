## 2026-10-17 - Native grep ABI mismatch falls back to ripgrep (senpi#3532)

### What changed

- `packages/coding-agent/src/core/tools/grep/select-engine.ts`: catches `NativeGrepSentinelMismatchError` when selecting the grep engine in `auto` mode, emits a diagnostic warning to stderr with the addon path and rebuild instructions, and falls back to ripgrep instead of failing. When `SENPI_GREP_ENGINE=native` is explicitly configured, the mismatch error is rethrown.

### Why

When the prebuilt native grep addon ABI does not match the running node/bun runtime, all grep operations fail completely. Falling back to `rg` allows grep to function while warning the user (#3532).

### Why an extension could not handle it

Grep engine selection is internal core logic of the coding-agent grep tool.

### Expected merge conflict zones

`packages/coding-agent/src/core/tools/grep/select-engine.ts` in `selectEngine()`.
