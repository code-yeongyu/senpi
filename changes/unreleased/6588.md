## 2026-11-13 - Read the macOS orphan start time in UTC (senpi#6588)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/terminal/orphan-reaper.ts` runs the darwin `ps -o lstart=,command=` read with `TZ=UTC` and parses its start as UTC.

### Why

- A local-time lstart is ambiguous in the repeated fall-back hour, so an orphan started then parsed an hour off its recorded start instant, was judged "unverifiable", and was never reaped (senpi#6589).

### Test

- `packages/coding-agent/test/suite/regressions/darwin-orphan-lstart-utc.test.ts` runs under `TZ=America/New_York` with a `ps` that honours the `TZ` it is given: main returns "unverifiable", this change "confirmed".
