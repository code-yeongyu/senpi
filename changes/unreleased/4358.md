## 2026-10-26 - Opt-in bash output secret redaction (senpi#4358)

### What changed

- `packages/coding-agent/src/core/settings-manager.ts`: add the optional `tools.bash.redactSecretsInOutput` boolean and a strict, default-false getter.
- `packages/coding-agent/src/core/agent-session.ts`: pass the resolved setting into the core bash definition and user `!cmd`/`!!cmd` execution.
- `packages/coding-agent/src/core/bash-executor.ts`: redact user-command output independently per stream before callbacks, retention and spill writes; settle final-token callbacks before persisting the result.
- Even with redaction disabled, deliver the final decoder chunk to `onChunk` before awaiting callback settlement on completion or abort. Output text is unchanged; callback ordering changes.
- `packages/coding-agent/src/core/tool-dispatch/child-bash-operations.ts`: forward the flag to shell jobs and retain stdout/stderr identity on output updates.

### Why

- Users can opt into redacting credential-shaped command output without changing the default shell behavior.

### Why an extension could not handle it

- The core settings, tool construction and child-operation transport own the output path before extensions see completed results.

### Expected merge conflict zones

- Shell settings accessors, core bash options in `_buildRuntime`, and the child bash job argument/update mapping.

## 2026-10-26 - Redact shell output before accumulation (senpi#4358)

### What changed

- `packages/coding-agent/src/core/tools/secret-output-redactor.ts`: bounded incremental tokenization for credential prefixes, JWTs, PEM private keys, Bearer credentials and secret-named assignments; preserve incomplete-token state across chunks and omit hidden OSC payloads.
- Review fixes: detect credential prefixes inside URL/path/assignment tokens at non-alphanumeric boundaries, consume full charset-designation escapes, anchor AUTH/AUTHORIZATION key segments, require token-shaped Bearer values, and end unclosed quoted assignments at a newline.
- Idle flush withholds tokens once a full public credential prefix or Bearer value has begun, including incomplete AWS/Google keys and JWTs. Mere prefix fragments (`I`, `e.g.`, `git`, `sk`, `AI`) remain visible. Delimiters release withheld tokens redacted or verbatim using complete-shape rules; EOF masks incomplete started shapes as public prefix plus `<redacted>`, without repeating published prefix characters. Secret assignment values remain masked from their first character.
- `packages/coding-agent/src/core/tools/bash.ts`: opt-in per-stream redaction before output accumulation, streaming updates, truncation, structured output and spill writes; flush pending tokens on completion or error.

### Why

- Redacting a final result is too late: a partial token or an unredacted spill file can already have reached the agent.

### Why an extension could not handle it

- The accumulator and its spill writes are internal to the core tool's execution.

### Expected merge conflict zones

- `BashOperations` output callback options and `createShellToolDefinition` output ingestion/finalization.

## 2026-10-26 - Apply bash redaction before persistent terminal retention (senpi#4358)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/terminal/settings.ts`: resolve the bash output setting with a disabled default.
- `packages/coding-agent/src/core/extensions/builtin/terminal/extension.ts`: load settings from the active session's agent directory, including SDK and isolated CLI sessions.
- `packages/coding-agent/src/core/extensions/builtin/terminal/extension-state.ts`: expose the resolved setting to command launches.
- `packages/coding-agent/src/core/extensions/builtin/terminal/tools/context.ts`: carry the optional output-redaction flag.
- `packages/coding-agent/src/core/extensions/builtin/terminal/tools/spawn.ts`: pass the setting into each new runtime.
- `packages/coding-agent/src/core/extensions/builtin/terminal/manager.ts`: accept runtime options at creation.
- `packages/coding-agent/src/core/extensions/builtin/terminal/runtime-session.ts`: redact before screen feeds, retained buffers and observers, including the final token at process exit. Flush ordinary idle prompts and completed controls after 50 ms; withhold started credential shapes, including short Bearer values, until a delimiter or exit. Clear idle timers at exit and disposal.
- `packages/coding-agent/src/core/extensions/builtin/terminal/tools/child-placement.ts`: forward the flag into terminal child jobs.

### Why

- Background notices, monitor overflow, screen reads and subsequent output peeks must consume the same sanitized stream as the initial bash result.

### Why an extension could not handle it

- This builtin owns the persistent terminal buffers and output observers, below external result hooks.

### Expected merge conflict zones

- Terminal runtime ingestion/exit, settings resolution and the session-start settings load in `packages/coding-agent/src/core/extensions/builtin/terminal/extension.ts`, and spawn/job option construction.
