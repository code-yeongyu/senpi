## 2026-11-22 - Restore thinking levels for the active model (senpi#3839)

### What changed

- `packages/coding-agent/src/core/sdk.ts`: Restore the selected model's branch-local thinking level on resume, below explicit startup options and above settings defaults. Write new startup thinking entries only after admission.
- `packages/coding-agent/src/core/agent-session.ts`: Wait for post-hook admission before journaling a favorite cycle's thinking level. Restore the previous level, selection, and source if the cycle is held or throws.

### Why

- `packages/coding-agent/src/core/sdk.ts`: The latest branch entry can belong to a different model.
- `packages/coding-agent/src/core/agent-session.ts`: A held or rejected cycle could leave the original model using the candidate's thinking level and record a level for a model that never became active.

### Why an extension could not handle it

- `packages/coding-agent/src/core/sdk.ts` and `packages/coding-agent/src/core/agent-session.ts` own startup resolution, admission, and session journaling.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/sdk.ts` startup thinking resolution and `packages/coding-agent/src/core/agent-session.ts` favorite-cycle admission and rollback.

### Fixed
- Resuming a session restores the selected model's own thinking level unless explicitly overridden. Held or rejected favorite cycles keep the active model's thinking level and leave the candidate's level out of the session history ([#3839](https://github.com/code-yeongyu/senpi/issues/3839)).
