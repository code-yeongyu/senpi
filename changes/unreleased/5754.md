## 2026-11-04 - Quit ends the active run before session_shutdown (senpi#5754, fixes #5753)

### What changed

- `packages/coding-agent/src/core/agent-session-runtime.ts`: `dispose({ endActiveRun: true })` awaits `this.session.abort()` before emitting `session_shutdown`, the order `teardownCurrent()` already uses for a replacement. Without the option `dispose()` is unchanged, so RPC host closes keep their bounded stuck-abort handling.
- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: both quit paths of `shutdown()` (signal and interactive) pass `endActiveRun: true`.
- `packages/coding-agent/test/suite/regressions/quit-aborts-run-before-shutdown.test.ts` (new): a quit while a tool runs sends no further provider request; a quit during a goal's turn stops the goal as an interrupt (`blocked`), so the next resume asks before continuing.

### Why

- A quit mid-turn disposed extension resources under the running tool. The tool failed and the dying process sent that failure to the model in one more request (and goal continuations kept firing), so a session closed mid-turn was reopened further along than where it was left.

### Why an extension could not handle it

- The order of the run's end and `session_shutdown` belongs to the runtime's own dispose.

### Expected merge conflict zones

- LOW: the head of `AgentSessionRuntime.dispose()` and its options type; the two `runtimeHost.dispose(...)` calls in `InteractiveMode.shutdown()`.

## 2026-11-04 - Quit ends the active run before shutdown (senpi#5754, fixes #5753)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: `shutdown()` disposes the runtime with `endActiveRun: true` on both the signal and the interactive quit path.

### Why

- A person quitting mid-turn must not leave the run going while extensions shut down.

### Why an extension could not handle it

- The quit sequence belongs to the interactive controller.

### Expected merge conflict zones

- LOW: the two `runtimeHost.dispose(...)` calls in `shutdown()`.
