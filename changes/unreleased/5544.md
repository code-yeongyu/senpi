## 2026-11-02 - Removing a session removes its codemode artifacts (senpi#3508)

### What changed

- `packages/coding-agent/src/core/session-manager.ts`: `discardHeaderOnlyFile()` removes the session's `<session>-artifacts/` directory (new `core/session-artifacts.ts`) after removing the header-only file.

### Why

- senpi-codemode creates that directory at session start, so a discarded session left its eval logs behind.

### Why an extension could not handle it

- Session deletion and the conversation-free discard are core session-file lifecycle paths; no extension event fires after the session file is removed.

### Expected merge conflict zones

- LOW: the body of `discardHeaderOnlyFile()`.

## 2026-11-02 - Removing a session removes its codemode artifacts (senpi#3508)

### What changed

- `packages/coding-agent/src/modes/interactive/components/session-selector.ts`: `deleteSessionFile()` removes the session's `<session>-artifacts/` directory once the session file is gone and reports `artifactsError` when it cannot; the selector names a leftover artifacts directory like a leftover image directory.

### Why

- Eval output from a session the user deleted on purpose stayed on disk.

### Why an extension could not handle it

- Session deletion and the conversation-free discard are core session-file lifecycle paths; no extension event fires after the session file is removed.

### Expected merge conflict zones

- LOW: the `deleteSessionFile()` return shape and the selector's delete status message.
