## 2026-11-28 - Re-report the resume command so a herdr restart reopens the session (senpi#7632)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/herdr/index.ts`: `reportResume()` sends the `pane.report_agent_session` start report and also re-sends the unchanged command every 5 seconds from an unref'd interval. The interval starts after the start report and `session_shutdown` clears it. A re-report carries no `session_start_source`.

### Why

- herdr drops a reported resume command whenever its process probe names a different agent in the pane (`reconcile_reported_resume`). That happens when herdr skips the senpi process's `HERDR_AGENT` hint because the process is in uninterruptible sleep, and finds the Claude subscription provider's `claude` child by name instead. The reporter sent the command once, so the next herdr restart reopened the pane as a plain shell. herdr still accepts the reporter's command after the flip, and an unchanged command is a no-op for it.

### Why an extension could not handle it

- This is the builtin reporter that owns the pane's resume command.

### Expected merge conflict zones

- LOW: the end of the `session_start` handler and the start of `session_shutdown` in `index.ts`.
