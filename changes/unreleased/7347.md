## 2026-11-22 - An idle Python kernel reaps children whose Popen handle a cell dropped (senpi#7246)

### What changed

- `packages/senpi-codemode/src/kernels/py/prelude.py`: `main()` runs `subprocess._cleanup()` after each handled message and on a 1 s timed wait on the command queue.

### Why

- CPython collects a child whose `Popen` handle was dropped only when a later `Popen` starts, so an idle kernel kept it as a zombie that `kill(pid, 0)` liveness checks read as alive. The reaper waits only on dropped handles: retained handles and `os.fork`, `os.spawn*` or `pty.fork` children keep their exit status.

### Why an extension could not handle it

- The kernel's own main loop is the only place that runs between cells in the kernel process.

### Expected merge conflict zones

- LOW: the command-queue wait at the top of the loop in `main()` in `prelude.py`.
