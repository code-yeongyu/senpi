## 2026-11-22 - Cached MCP tool schemas compile on first use (senpi#5402)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/mcp/modern/tool-schema.ts`: one shared JSON Schema 2020-12 compiler per process, validators keyed by schema content and kept for the process (failures too); nested ids and anchors are cleared from the shared compiler after each compile.
- `catalog-cache.ts` and `catalog.ts`: loading a cached catalog no longer compiles any tool schema; an invalid schema is refused when its tool is used, with the same warning, and its siblings keep working.

### Why

- A cached modern catalog of 170 tools compiled 340 validators synchronously at session attach, freezing input for about 1.8 s right after the first frame.

### Why an extension could not handle it

- The MCP builtin owns catalog loading and schema validation; the cost sat inside its own load path.

### Expected merge conflict zones

- LOW: `compileModernSchema` and the modern-tool filters in the catalog load path.
