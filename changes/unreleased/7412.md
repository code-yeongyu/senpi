## 2026-11-24 - Host session model ids may contain slashes (senpi#7139)

### What changed

- `packages/coding-agent/src/cli/host-session-command.ts`: `parseModel` now splits on the first `/` only, so `opencodex/anthropic/claude-opus-5-5` parses as provider `opencodex` with id `anthropic/claude-opus-5-5`.

### Why

- Model ids legitimately contain slashes (e.g. `opencodex/anthropic/claude-opus-5-5`); requiring exactly two segments rejected them with "Model must be provider/id." (senpi#7139).

### Why an extension could not handle it

- `parseModel` is core CLI argv parsing for `host session model` and `open --model`; no extension hook covers it.

### Expected merge conflict zones

- LOW: a single small function in `host-session-command.ts`; no other open PR touches `parseModel`.
