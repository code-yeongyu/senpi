## 2026-11-03 - /model fetches catalogs over the network and names each refresh error (senpi#839)

### What changed

- `packages/coding-agent/src/modes/interactive/model-catalog-refresh.ts`: new `refreshModelCatalogsOnRequest` refreshes with `allowNetwork: true` unless `OFFLINE` is set, through its own per-runtime coordinator; `refreshModelCatalogs` keeps the runtime's network policy. New `describeModelRefreshErrors` names each failed provider with its error message.
- `packages/coding-agent/src/modes/interactive/components/model-selector.ts`: the `/model` selector refreshes through `refreshModelCatalogsOnRequest` and shows `describeModelRefreshErrors`.
- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: `/model <term>` (findExactModelMatch) and the scoped-model picker refresh through `refreshModelCatalogsOnRequest`; `/model <term>` warns with `describeModelRefreshErrors`. The startup background refresh still calls `refreshModelCatalogs`.

### Why

- `packages/coding-agent/src/modes/interactive/model-catalog-refresh.ts`: session runtimes are created offline, so every interactive refresh ran offline and a credentialed provider with an empty stored catalog (Ollama with only an env key) never listed a model.
- `packages/coding-agent/src/modes/interactive/components/model-selector.ts`: a failed refresh showed only the provider id, hiding the cause.
- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the other user-requested refresh paths had the same offline gap; startup must stay offline.

### Why an extension could not handle it

- `packages/coding-agent/src/modes/interactive/model-catalog-refresh.ts`: the network policy of the built-in `/model` refresh is decided inside interactive mode, before any extension hook.
- `packages/coding-agent/src/modes/interactive/components/model-selector.ts`: the selector's error row is rendered by the built-in component.
- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: `/model` and the scoped-model picker are built-in commands.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/modes/interactive/model-catalog-refresh.ts` coordinator class; `components/model-selector.ts` `refreshModels` error branch; `interactive-mode.ts` `findExactModelMatch` and the scoped-model selector refresh call.
