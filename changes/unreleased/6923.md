## 2026-11-17 - A prompt can name the leaf it was decided at (senpi#6922)

### What changed

- `packages/coding-agent/src/modes/rpc/method-classes-schema-session.ts`: `prompt` accepts optional `expectedLeafId`.
- `packages/coding-agent/src/modes/rpc/connection-handler.ts`: the `prompt` case calls `refusePromptAtMovedLeaf` (new `prompt-expected-leaf.ts`) before chain admission, notice holding or turn admission. A stale `expectedLeafId` is refused `stale_leaf` with the edit commands' `assertExpectedLeaf` message, compared against `lifecycleEditLeaf` so lifecycle bookkeeping after the turn end is not a move. Combining it with `streamingBehavior` is refused `invalid_argument`, because a queued prompt runs at a later leaf. Nothing is appended or sent on either refusal.

### Why

- A client that decides to run a prompt at one leaf (a desktop "Run it" on an unanswered prompt) could check the leaf, but an entry landing between that check and the prompt made it run from wherever the session had moved.

### Why an extension could not handle it

- Command admission happens in the RPC connection handler before any extension hook sees the prompt; an `input` handler runs after the command is already accepted.

### Expected merge conflict zones

- LOW: the top of the `prompt` case in `connection-handler.ts`; the `prompt` schema field list.

## 2026-11-17 - A terminal's session-control endpoint refuses expectedLeafId by name (senpi#6922)

### What changed

- `packages/coding-agent/src/modes/interactive/session-control-input-commands.ts`: `expectedLeafId` is in `UNSERVED_INPUT_FIELDS`, so a `prompt` carrying it is refused with `unsupported_field` instead of being admitted with the guard silently dropped.

### Why

- That endpoint delivers through the session's external admission, which queues the text and starts the turn later, at a leaf an admission-time check never sees; refusing by name keeps the guard's promise honest.

### Why an extension could not handle it

- The terminal control endpoint's field allow-list is fixed in core before any extension sees the input.

### Expected merge conflict zones

- LOW: `UNSERVED_INPUT_FIELDS`.
