## 2026-11-25 - Load deferred tools by exact catalog name (senpi#7459)

### What changed

- `tool_search` accepts `load: true` to activate one exact registered name within the requested source and group. Plain search leaves tools inactive.

### Why

- A model that can only call declared tools needs the selected tool to appear in the next provider request. Ranked search can omit an exact name when similarly named entries share a normalized name.

### Why an extension could not handle it

- The built-in catalog owns lazy activation and applies the existing eligibility checks before the provider receives the next active tool set.

### Expected merge conflict zones

- LOW: the shared tool-search definition and its activation service.
