## 2026-11-22 - Todo labels are written in the user's language (senpi#4107)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/todotools/tools/todo.ts`: the `phase` and task-content parameter descriptions say the label is in the language the user writes in.
- `packages/coding-agent/src/core/extensions/builtin/todotools/prompt.ts`: the Anatomy lines for task content and phase names say the same.

### Why

- After long English tool or skill output, Claude wrote todo labels in English while replying in the user's language; nothing in the todo tool named the label language, unlike the eval `summary` description.

### Why an extension could not handle it

- The todo tool's schema descriptions and prompt are defined by this builtin extension; another extension cannot rewrite them.

### Expected merge conflict zones

- LOW: the todo parameter schema descriptions and the prompt Anatomy section (fork-only extension).
