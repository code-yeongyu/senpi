## 2026-11-22 - Separate hosted search context from iteration billing (#7208)

### What changed

- `packages/ai/src/api/anthropic-messages.ts` records the latest sampling iteration as request context. A hosted tool call without a sampling measurement leaves context unknown, not equal to the bill.

### Why

- Each server-side search can bill the same prompt again. Adding those samples made a half-full window appear over capacity (#7207).

### Why an extension could not handle it

- The provider adapter sees the raw iteration breakdown; the normalized billing fields do not retain it.

### Expected merge conflict zones

- Anthropic native block handling and final `message_delta` usage normalization.

## 2026-11-22 - Count native blocks when estimating harness context (#7208)

### What changed

- `packages/agent/src/harness/compaction/compaction.ts` uses the AI message estimator for assistant turns, including native search result blocks.

### Why

- A turn without per-sample usage needs a transcript estimate that includes the result.

### Why an extension could not handle it

- The harness computes its own compaction boundary from its stored messages.

### Expected merge conflict zones

- The assistant branch of `estimateTokens`.

## 2026-11-22 - Include native results in local compaction estimates (#7208)

### What changed

- `packages/coding-agent/src/core/compaction/compaction.ts` counts native blocks alongside text, thinking and local tool calls.

### Why

- When the provider omits per-sample usage, the next request still carries those results.

### Why an extension could not handle it

- This estimate supplies the session's threshold and cut-point calculations.

### Expected merge conflict zones

- `computeEstimateTokens` and the local transcript estimator.
