## 2026-11-22 - Emit each selected skill root once (#4215)

### What changed
- `packages/coding-agent/src/core/package-manager.ts` emits one entry per distinct `(kind, selectedRoot, projectRoot)` in first-seen order. `packages/coding-agent/src/core/skill-access.ts` documents that the walker compares exact path spellings.

### Why
- `packages/coding-agent/src/core/package-manager.ts` previously emitted the same selected root once per skill. The comment in `packages/coding-agent/src/core/skill-access.ts` implied the walk applied ignore rules.

### Why an extension could not handle it
- `packages/coding-agent/src/core/package-manager.ts` constructs the resolved paths before consumers receive them; `packages/coding-agent/src/core/skill-access.ts` owns the walker.

### Expected merge conflict zones
- `packages/coding-agent/src/core/package-manager.ts`: `toResolvedPaths`; `packages/coding-agent/src/core/skill-access.ts`: the exact-spelling deduplication comment.
