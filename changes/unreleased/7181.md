## 2026-11-21 - The pre-push hook shares CI's fast static checks (senpi#7181)

### What changed

- `.github/workflows/ci.yml`: The `check` job explicitly marks runner setup, tests, build verification, and reporting as CI-only. Its remaining steps run in Bash both on GitHub and in the local pre-push hook.

### Why

- `.github/workflows/ci.yml`: New quick checks apply locally without a second list of commands to maintain.

### Why an extension could not handle it

- `.github/workflows/ci.yml`: Git and GitHub Actions run these repository checks outside the Senpi runtime.

### Expected merge conflict zones

- LOW: `.github/workflows/ci.yml`, the static check job's shell defaults and step IDs.

## 2026-11-21 - Branch pushes run the fast checks (senpi#7181)

### What changed

- `.husky/pre-push`: The previous stub runs the static check job's local steps and the changelog checker for clean `HEAD` branch pushes. For clients running without a login shell, the hook also checks Bun's standard install directory if Bun is not on `PATH`.

### Why

- `.husky/pre-push`: Catch errors before sending a branch to CI, and refuse to check a tree that doesn't match the pushed commit.

### Why an extension could not handle it

- `.husky/pre-push`: Git runs the hook independently of Senpi.

### Expected merge conflict zones

- LOW: `.husky/pre-push` is fork-only.

## 2026-11-21 - Contributor setup activates Git hooks (senpi#7181)

### What changed

- `package.json`: `bun run setup` installs dependencies with lifecycle scripts disabled, then installs and verifies the Git hooks. `setup:hooks` also repairs an existing installation.

### Why

- `package.json`: `bun install --ignore-scripts` does not run Husky's `prepare` lifecycle.

### Why an extension could not handle it

- `package.json`: The repository setup runs before any Senpi extension loads.

### Expected merge conflict zones

- LOW: `package.json`, root setup scripts.

## 2026-11-21 - Development bootstrap and pre-push enforce repository checks (senpi#7181)

### What changed

- `scripts/devenv-setup.mjs`: Standard developer bootstrap also activates the hooks in a Git checkout.
- `scripts/install-git-hooks.mjs`: Installs and checks Husky's active pre-push wrapper.
- `scripts/pre-push.mjs`: Reads the static check steps from CI, rejects unsupported step semantics, and runs the existing changelog checker.

### Why

- `scripts/devenv-setup.mjs`, `scripts/install-git-hooks.mjs`, and `scripts/pre-push.mjs`: The normal script-disabled install must still activate the same fast checks CI runs.

### Why an extension could not handle it

- `scripts/devenv-setup.mjs`, `scripts/install-git-hooks.mjs`, and `scripts/pre-push.mjs`: These are repository and Git tooling.

### Expected merge conflict zones

- LOW: `scripts/devenv-setup.mjs`, the dependency setup block; `scripts/install-git-hooks.mjs` and `scripts/pre-push.mjs` are fork-only.
