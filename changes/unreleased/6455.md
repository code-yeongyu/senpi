## 2026-11-11 - Each import attempt stages in a folder of its own (senpi#4016)

### What changed

- `packages/coding-agent/src/core/session-move/import-staging.ts` (new): where ONE import attempt stages, and the age sweep of folders attempts died in.
- `packages/coding-agent/src/core/session-move/import.ts`: the import stages in its attempt's folder and commits only what it staged.

### Why

- Two imports of one move pass `beginReceive` together and staged in one folder per move: the later one removed that folder and copied again while the earlier one was still assembling in it, and the earlier one then committed whatever was there.

### Why an extension could not handle it

- It is the engine's own import path.

### Expected merge conflict zones

- LOW: the staging path in `import.ts`.

### Fixed

- Two imports of one session move no longer assemble in the same staging folder: each attempt stages in a folder of its own and commits only what it staged, and folders left by attempts that died are removed by age ([#6455](https://github.com/code-yeongyu/senpi/pull/6455)).
