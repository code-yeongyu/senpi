## 2026-11-25 - Opt-in antigravity-acp builtin provider (senpi#7440)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/antigravity-acp/` (new): opt-in `antigravity-acp` builtin provider (`enabled: false` by default) driving the official `agy acp` (1.5.1+) JSON-RPC 2.0 stdio server with `localOnly: true` and a loopback bearer-authenticated HTTP MCP host tool bridge (`senpi-host`).
  - `settings.ts`, `availability.ts`, `auth.ts`: restricts `authMethod` strictly to `"gemini-api-key"` (default, requires `GEMINI_API_KEY`) and `"agent-platform"` (Vertex AI / Gemini Enterprise, requires `GOOGLE_CLOUD_PROJECT`), failing closed without spawning when credentials are absent; reads settings strictly from `<agentDir>/settings.json` and `SENPI_ANTIGRAVITY_ACP_*` env vars so untrusted project configs cannot enable the provider or set `executablePath` (senpi#6362).
  - `session.ts`, `acp-client.ts`, `workspace.ts`, `environment.ts`: spawns `agy acp --agent senpi-host --process-per-session` with `windowsHide: true` (senpi#3965), an allowlisted child environment, isolated per-session restricted agent config (`tools: []`, `excludeDefaultComponents: true`, `commandExecutionPolicy: "off"`), `session/request_permission` restricted to `mcp_senpi-host_*` bridge calls, and cross-process `session/resume` with `session/new` bootstrap fallback.
  - `stream.ts`, `prompt.ts`, `bridge-server.ts`, `tool-bridge.ts`, `models.ts`, `index.ts`: extracts system prompts and tools from normalized `TranscriptContext`, passes system prompts via `_meta.antigravity.systemPrompt.append`, preserves native image blocks and `agent_thought_chunk` thinking deltas, compacts and coalesces MCP bridge tool schemas under a 28 KB byte budget, and rewrites `tool_search` results to surface canonical `mcp_senpi-host_*` names without mutating Senpi's active tool set.
- `packages/coding-agent/src/core/extensions/builtin/index.ts`, `packages/coding-agent/src/core/extensions/builtin/AGENTS.md`: registers `antigravity-acp` beside `cursor-cli-oauth` and `vertex-model-garden`.
- `packages/coding-agent/test/antigravity-acp/antigravity-acp.test.ts` (new): unit and fake-ACP end-to-end tests covering environment isolation, model tier clamping, schema compaction, MCP tool bridging, slow parked-tool detachment, `session/resume`, normalized `TranscriptContext` extraction, strict `authMethod` allowlisting, and untrusted project settings isolation.
- `scripts/realm-census.json`: classifies the 22 module-scope bindings in `builtin/antigravity-acp/`.

### Why

- Follows up on RFC senpi#7373: integrates `agy acp` cleanly into Senpi as a zero-token-custody, opt-in builtin provider using only Google's documented external-harness authentication paths.

### Why an extension could not handle it

- It is one. Every runtime, protocol, and tool-bridge responsibility lives inside `builtin/antigravity-acp/` using public extension registration APIs, with zero edits to `packages/coding-agent/src/core/` outside `builtin/index.ts`.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/extensions/builtin/index.ts`, `packages/coding-agent/src/core/extensions/builtin/AGENTS.md`, and `scripts/realm-census.json` (each adds entries for `antigravity-acp`).
