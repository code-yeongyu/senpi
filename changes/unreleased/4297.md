## 2026-10-26 - A torn JSONL append never refuses the session (senpi#4295)

### What changed

- `packages/agent/src/harness/session/jsonl/storage.ts`: `openV4` replays through `replayV4Lines` and hands damaged bytes to `JsonlRepairs` instead of throwing on the first bad interior line. `applyCommit` repairs before every append, records a failed append, and advances the sequence high-water mark past the failed commit so its sequences are never handed out again.
- `packages/agent/src/harness/session/jsonl/salvage.ts` (new): a line that is not JSON is damage from a torn write; the first suffix that starts a record and replays is kept (a torn append glued to the next one), the rest is set aside. A framed record that does not replay (a reused sequence, a missing parent) is set aside. A JSON record this version cannot frame still refuses the session.
- `packages/agent/src/harness/session/jsonl/repair.ts` (new): `JsonlRepairs` copies damaged bytes to `<file>.torn-<time>` atomically (never deleted), rewrites the session file atomically once, and reports one `JsonlStorageRecovery` with a user-facing message. A repair the disk refuses on open is deferred to the next append.
- `packages/agent/src/harness/session/jsonl/io.ts`: `parseJsonlTransactionValue` frames an already-parsed line.
- `packages/agent/src/harness/session/jsonl/types.ts`: `JsonlStorageRecovery`, `JsonlRecoveryCause`, and `onRecovery` on `JsonlStorageOptions` and `JsonlSessionRepoOptions`.
- `packages/agent/src/harness/session/jsonl/repo.ts`: passes `onRecovery` to every storage it opens or creates.

### Why

- An append torn by a full disk (ENOSPC) was followed by the next commit on the same line and reused the failed commit's sequence, so reopening refused the whole session at every tear offset (`Invalid JSONL storage <file>: line N`).

### Why an extension could not handle it

- The append, replay, and sequence assignment live inside `JsonlStorage`; no hook runs between a failed append and the next one, or before `openV4` throws.

### Expected merge conflict zones

- MEDIUM: `packages/agent/src/harness/session/jsonl/storage.ts`, `openV4` and `applyCommit`.
- LOW: `packages/agent/src/harness/session/jsonl/io.ts` (`parseJsonlTransaction`), `types.ts` option interfaces, `repo.ts` storage option construction.

### Fixed
- A JSONL session whose append was torn by a full disk no longer refuses to open: damaged records are set aside in `<file>.torn-<time>`, every other record is kept, failed sequences are never reused, and `onRecovery` reports each repair once ([#4295](https://github.com/code-yeongyu/senpi/issues/4295))
