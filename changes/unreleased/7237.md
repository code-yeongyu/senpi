## 2026-11-22 - Summarized thinking is timed from the response start (senpi#3399, PR #7237)

### What changed

- `packages/ai/src/api/anthropic-messages.ts`: when the sent request's `thinking.display` was `"summarized"` and a non-redacted thinking block streamed, the final usage is stamped `reasoningSummarized: true`. The stamp is read from the params actually sent, so a sanitized or omitted display never earns the marker.
- `packages/ai/src/api/bedrock-converse-stream.ts`: same stamp for Anthropic-Claude models whose request carried the `"summarized"` display (the resolution extracted into `bedrockThinkingDisplay`, replacing the inline GovCloud ternary). Non-Anthropic models (raw reasoning, not a summary) and GovCloud (no display field sent) stay unstamped.

### Why

- A summarized-thinking reply bills its reasoning tokens inside `usage.output` without a `usage.reasoning` count, so the TPS notice and the persisted generation window (`packages/agent/src/response-timing.ts`, senpi#3879) started at the first summary chunk and overstated the rate (senpi#3399).

### Why an extension could not handle it

- Only the provider adapter knows the request's reasoning-display mode; the timing layer must not guess summary semantics from stream content.

### Expected merge conflict zones

- LOW: usage finalization tails of both stream adapters; the Bedrock display extraction sits on the same lines as the GovCloud display omission.

## 2026-11-22 - AiUsage carries a summarized-reasoning marker (senpi#3399)

### What changed

- `packages/ai/src/types.ts`: `AiUsage` gains optional `reasoningSummarized?: true` — the billed `output` includes reasoning the provider delivered only as a summary. Stamped only by adapters that know the request's reasoning-display mode.

### Why

- Gives `reasonedBeforeFirstDelta` (senpi#3393, senpi#3399) a contract-based signal so a streamed summary no longer short-circuits the generation window to the first summary chunk.

### Why an extension could not handle it

- The marker travels on the provider-neutral usage object the adapters build; extensions never see the request's display mode.

### Expected merge conflict zones

- LOW: directly below `reasoning` in `AiUsage`.
