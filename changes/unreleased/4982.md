## 2026-10-30 - Release test evidence from a green local whole-suite receipt (senpi#4981)

### What changed

- `scripts/release.mjs`: new `--local-receipt-sha <sha40>` and `--local-receipt <label>` flags. The evidence plan (`scripts/release-evidence.mjs`) runs before any work. With a receipt at the exact pinned `--sha`, the release skips the hosted CI wait and runs clean, build and check only (no npm test) before stamping. It refuses a regenerated model catalog.

### Why

- senpi#4981: merges are decided on a green local whole-suite receipt. The release could only wait for hosted CI (queued for hours, or red for hosted-only reasons, senpi#4964) or re-run the suite in-job (senpi#2291 hang).

### Why an extension could not handle it

- `scripts/release.mjs` is release tooling that runs outside the agent runtime.

### Expected merge conflict zones

- LOW: `parseArgs`, `secureCiEvidence`, `runForcedTests` and the evidence plan in `main()` of `scripts/release.mjs`.
