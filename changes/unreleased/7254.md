## 2026-11-22 - Select ready compaction keys without sorting the backlog (#4734)

### What changed

`packages/coding-agent/src/modes/rpc/compact-ready-keys.ts` maintains ordered membership; `packages/coding-agent/src/modes/rpc/compact-content-index.ts` owns that index and `packages/coding-agent/src/modes/rpc/compact-index-compactor.ts` iterates a snapshot lazily.

### Why

`packages/coding-agent/src/modes/rpc/compact-index-compactor.ts` copied and sorted every ready key before each round. Maintaining order in `packages/coding-agent/src/modes/rpc/compact-ready-keys.ts` trades more expensive individual updates for bounded selection work per key on large backlogs.

### Why an extension could not handle it

`packages/coding-agent/src/modes/rpc/compact-content-index.ts` and `packages/coding-agent/src/modes/rpc/compact-index-compactor.ts` own membership and page selection internally.

### Expected merge conflict zones

Ready membership updates in `packages/coding-agent/src/modes/rpc/compact-content-index.ts`, ordered traversal in `packages/coding-agent/src/modes/rpc/compact-ready-keys.ts`, and the live membership check in `packages/coding-agent/src/modes/rpc/compact-index-compactor.ts`.
