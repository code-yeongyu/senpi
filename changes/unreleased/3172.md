## 2026-10-26 - Classify retired-context dispatch failures (senpi#3149)

### What changed

- `packages/coding-agent/src/core/extensions/runner.ts`: suppress only typed stale-context failures on a retired runner, including budgeted lifecycle dispatch; preserve genuine failures and direct command reports.
- `packages/coding-agent/src/core/extensions/context-dispatch.ts`: pass the caught cause with context-hook error reports so the runner can classify it before formatting loses its type.

### Why

- `packages/coding-agent/src/core/extensions/runner.ts`: later handlers can touch a retired generation during session replacement; matching retirement text also hid unrelated failures.
- `packages/coding-agent/src/core/extensions/context-dispatch.ts`: a formatted message cannot distinguish a stale-context exception from an ordinary error containing the same text.

### Why an extension could not handle it

- `packages/coding-agent/src/core/extensions/runner.ts`: the host owns generation guards, dispatch budgets and error publication.
- `packages/coding-agent/src/core/extensions/context-dispatch.ts`: the shared dispatcher catches failures before extensions can intercept their reports.

### Expected merge conflict zones

- `packages/coding-agent/src/core/extensions/runner.ts`: lifecycle failure reporting, dedicated emit catch blocks and context dispatch delegation.
- `packages/coding-agent/src/core/extensions/context-dispatch.ts`: the error callback contract and both context-hook catch blocks.
