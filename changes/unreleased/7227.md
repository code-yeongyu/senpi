## 2026-11-22 - A bash run with no output hands eval callers empty text (senpi#7209)

### What changed

- `packages/senpi-codemode/src/tool/tool-result-marshal.ts`: `marshalToolResult` leaves only the empty-output placeholder out of `.text`. Injected nested `AGENTS.md` context, project rules and other model-only notices stay in `.text` as before.
- `packages/senpi-codemode/src/tool/call-capture.ts`: `toolCallResultPreview` skips model-only parts, as the result renderer does.

### Why

- `tool.bash({ command: "true" }).text` was the literal `"(no output)"`, so eval code could not tell empty output from that text and `if (out)` guards misfired.
- The injectors record their context as delivered when it is attached to the result. Through eval the cell's text is how that context reaches the model, so it must not be dropped.

### Why an extension could not handle it

- The marshal and the nested-call preview are this extension's own boundary between a host tool result and what a cell and its row show.

### Expected merge conflict zones

- LOW: the text-part filter at the top of `marshalToolResult` and the part loop in `toolCallResultPreview`.

## 2026-11-22 - The bash empty-output placeholder is a named model-only part (senpi#7209)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/terminal/tools/bash.ts` and `packages/coding-agent/src/core/tools/shell-output.ts`: a run with no output returns `emptyOutputPlaceholder()`, a model-only `(no output)` part, instead of visible text.
- `packages/coding-agent/src/core/tools/model-only-text.ts`: `emptyOutputPlaceholder` and the predicate `isEmptyOutputPlaceholder`.

### Why

- The placeholder exists because providers need a non-empty block; it is not output, and programmatic callers (eval's `tool.bash`) must see empty text without dropping other model-only parts.

### Why an extension could not handle it

- Both bash tools build their own result content; the placeholder is identified where it is created.

### Expected merge conflict zones

- LOW: the success return of the PTY bash foreground run and `formatOutput` in shell-output.

## 2026-11-22 - The SDK exports isEmptyOutputPlaceholder (senpi#7209)

### What changed

- `packages/coding-agent/src/index.ts`: exports `isEmptyOutputPlaceholder` from `core/tools/model-only-text.ts`.

### Why

- `packages/coding-agent/src/index.ts` is the SDK surface the eval extension imports from; its marshal drops only that placeholder from a nested tool's `.text`.

### Why an extension could not handle it

- `packages/coding-agent/src/index.ts` is the only public entry an extension package can import the predicate from.

### Expected merge conflict zones

- LOW: one export line beside the tool-machine exports in `packages/coding-agent/src/index.ts`.
