## 2026-10-30 - Classify skill diagnostics at the source (senpi#4940)

### What changed

- `packages/coding-agent/src/core/skills.ts`: classify collisions, parse errors, read errors and metadata validation separately; YAML parse errors retain parser line information and include a scalar repair hint.
- `packages/coding-agent/src/core/resource-loader.ts`: classify a missing explicit skill path as a read error.
- `packages/coding-agent/src/core/diagnostics.ts`: add optional `kind` and `hint` fields without changing existing diagnostic fields.

### Why

- `packages/coding-agent/src/core/skills.ts`, `packages/coding-agent/src/core/resource-loader.ts` and `packages/coding-agent/src/core/diagnostics.ts`: startup could not distinguish invalid files from duplicate skill names, and presented parse and read failures as conflicts.

### Why an extension could not handle it

- `packages/coding-agent/src/core/skills.ts`, `packages/coding-agent/src/core/resource-loader.ts` and `packages/coding-agent/src/core/diagnostics.ts`: core owns resource discovery and its diagnostics before extensions render anything.

### Expected merge conflict zones

- `packages/coding-agent/src/core/skills.ts`: loader catch blocks and collision records.
- `packages/coding-agent/src/core/resource-loader.ts`: missing skill path diagnostic.
- `packages/coding-agent/src/core/diagnostics.ts`: ResourceDiagnostic optional fields.

## 2026-10-30 - Separate invalid skill files from name conflicts (senpi#4940)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: reserve Skill conflicts for collisions and show parse/read/validation diagnostics under Invalid skill files, retaining paths, parser errors and repair hints on quiet startup.

### Why

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the former shared heading incorrectly suggested that malformed YAML and missing files were duplicate-name collisions.

### Why an extension could not handle it

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the interactive host owns startup resource notices.

### Expected merge conflict zones

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: formatDiagnostics and showLoadedResources.
