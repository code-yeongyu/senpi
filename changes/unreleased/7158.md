### Fixed
- On macOS, tool calls that name a path under `/home` (an automount that may never answer) no longer leave filesystem threads stuck. Enough of them used to stall every file operation in the engine while the session kept running. Such paths are now resolved from the mount table alone ([#7158](https://github.com/code-yeongyu/senpi/pull/7158))
