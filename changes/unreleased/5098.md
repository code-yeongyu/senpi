## 2026-10-30 - Cold seed replays the history as native frames, flat fallback once (senpi#5098)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/session-stream.ts`: a resident cold seed (flatten/bootstrap, or a failed reattach) in `coldSeedReplay: "frames"` mode sizes the seed, writes it with `writeSeedTranscript` into the attempt lane's transcript root, then spawns the entry with `resume: <seed id>` and sends only the final user message (or `CONTINUE_TURN_INSTRUCTION` after trailing tool results). The seeded assistant uuids populate `assistantUuidByIndex`, keyed by sent user/tool-result count. The entry is created after the size check, so an over-budget seed spawns and writes nothing. `residentSessionMessages` re-runs the turn once with the flat replay when the frames seed is rejected before any visible output (`flatReplayReason: "frames_seed_rejected"`).
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/stream.ts`: the one-shot lane passes the same seed through `Options.sessionStore` + `resume`, with the same once-only flat fallback. Both lanes record a `claude_sdk_oauth_frames_seed_rejected` diagnostic. A resident lane in frames mode pins `CLAUDE_CODE_PROMPT_CACHE_TTL` like the one-shot lane.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/cold-seed-frames.ts` (new): `buildColdSeedFrames`, `framesApply`, `seedConfigDir`, `seedSessionStore`, `isFramesSeedRejection`, `withFlatFallbackOnce`.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/history-transcript.lazy.ts` (new): the lazy boundary for `history-transcript.ts`, which reaches pi-ai's Anthropic Messages conversion (about 20 ms at startup otherwise).
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/history-transcript.ts`: reaches `toAnthropicMessageParams` through a top-level dynamic import, so the bundler keeps pi-ai's Anthropic Messages module in its own `anthropic-messages-*.js` chunk with the `claudeCodeVersion` declaration a downstream installer rewrites; `isFramesSeedRejection` is module-private.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/cold-seed-images.ts`: `frameHistoryImages` applies the frame image policy: hash dedupe, a cut at 2x the target in target-sized steps (tool images first), and a 20 MiB byte cap in half-cap steps.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/settings.ts`: `coldSeedReplay` (`frames` default, `flat`) and `SENPI_CLAUDE_SDK_OAUTH_REPLAY`.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/session-observability.ts`: `replayMode` on flatten observations and in the log; reason `frames_seed_rejected`.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/prompt-cache-ttl.ts`: `pinnedPromptCacheTtl(env)`.
- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/sdk-boundary.ts`: re-exports the SDK `SessionStore` type.

### Why

- senpi#1977 and the image half of senpi#3231: the flattened envelope lost tool structure, never matched a native transcript (no cache reuse), and surfaced historical tool images as fresh user attachments. A probe against the pinned Claude Code binary showed that a seeded transcript plus `resume` replays the turns natively and in order.

### Why an extension could not handle it

- It is extension code; this entry records the behavior change for the extension's tracker.

### Expected merge conflict zones

- HIGH: `session-stream.ts` `createResidentAttempt` (entry creation moved after the size check) and `residentSessionMessages`; `stream.ts` `buildOptions` and the one-shot `queryWithAuthLane` call.
- LOW: the `ContinuityReason` union and `SANITIZED_REASONS` in `session-observability.ts`; the provider settings parsers in `settings.ts`.

### Changed

- The Anthropic subscription provider replays the history of a cold seed as native turns of a resumed Claude Code session instead of one flattened message, so tool calls and tool images keep their structure; set `anthropicSubscriptionProvider.coldSeedReplay` to `"flat"` (or `SENPI_CLAUDE_SDK_OAUTH_REPLAY=flat`) for the previous behavior ([#5098](https://github.com/code-yeongyu/senpi/pull/5098))
