## 2026-11-23 - Document the existing TTSR settings switch (senpi#4621)

### What changed

- The settings reference documents `disabledBuiltinExtensions: ["ttsr"]`. An SDK regression exercises a stream with TTSR disabled at startup and re-enabled after a session reload.

### Why

- The desktop launches the runtime with fixed arguments, so users need a way to turn off TTSR without passing `--ttsr-disabled`.

### Why an extension could not handle it

- The existing settings switch skips loading the builtin itself. No runtime code changed.

### Expected merge conflict zones

- LOW: The resources section of the settings reference.
