## 2026-11-22 - An empty print run fails with a usage error (senpi#3521)

### What changed

- `packages/coding-agent/src/main.ts`: a print or JSON run with no prompt, stdin, `@file` content or later message prints "Error: print mode needs a prompt. ..." and exits 1 before any model is resolved.
- `packages/coding-agent/src/cli/initial-message.ts`: new `hasPrintInput(initial, laterMessages)`.

### Why

- `senpi -p` with nothing to send exited 0 without output, so a caller could not tell it from a quiet success.

### Why an extension could not handle it

- Argument handling and mode dispatch happen in the CLI entry before extensions run.

### Expected merge conflict zones

- LOW: the lines after `prepareInitialMessage` in `main.ts`; the end of `cli/initial-message.ts`.
