## 2026-10-29 - Host status snapshot, compact subscribe and RpcClient repair (S15a-2, part of #4272)

### What changed

- `packages/coding-agent/src/modes/rpc/compact-admission-baseline.ts`: Support the seq-zero host snapshot identity under the existing answer barrier.
- `packages/coding-agent/src/modes/rpc/compact-admission-routing.ts`: Route every selected subscription delta by its actual server ID; leave legacy subscriptions unchanged.
- `packages/coding-agent/src/modes/rpc/compact-event-leases.ts`: Reuse the ordinary-event substrate for streamed snapshot records.
- `packages/coding-agent/src/modes/rpc/compact-record-staging.ts`: Stream a known snapshot chunk source through bounded staging without a snapshot array.
- `packages/coding-agent/src/modes/rpc/compact-status-snapshot.ts`: Own the host-wide seq-zero immutable snapshot, lease and consumption lifetime.
- `packages/coding-agent/src/modes/rpc/compact-subscribe-admission.ts`: Register the actual returned subscription, activate behind the barrier and clean cancellation/failure with that ID.
- `packages/coding-agent/src/modes/rpc/recovery-page-command.ts`: Echo seq-zero subscription routing on every host snapshot page.
- `packages/coding-agent/src/modes/rpc/rpc-client-admissions.ts`: Register before send, fence generations and drive shared event-based repair with receive-time backoff.
- `packages/coding-agent/src/modes/rpc/rpc-client.ts`: Delegate compact admission/repair wiring to the small helper; preserve legacy requests and shrink the oversized client.
- `packages/coding-agent/src/modes/rpc/rpc-host-command-types.ts`: Declare the validated compact subscribe identity.
- `packages/coding-agent/src/modes/rpc/session-attachment-gate.ts`: Let the scoped recovery owner authenticate host-wide snapshot pages without an attachment.
- `packages/coding-agent/src/modes/rpc/session-event-writer-recovery.ts`: Expose bounded subscription-ID routing and snapshot-baseline hooks.
- `packages/coding-agent/src/modes/rpc/session-router-routing.ts`: Select compact subscribe only for a present admission ID with the flag enabled.
- `packages/coding-agent/src/modes/rpc/session-status-commands.ts`: Pass an optional streaming snapshot sink through subscription acceptance.
- `packages/coding-agent/src/modes/rpc/session-status-record.ts`: Share the behavior-identical status projection without growing the existing stream.
- `packages/coding-agent/src/modes/rpc/session-status-stream.ts`: Stream snapshot rows synchronously with one cut timestamp while preserving legacy inline output.
