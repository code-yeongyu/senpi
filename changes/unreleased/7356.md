## 2026-11-22 - Leaving GPT after a reload restores the edit tools (senpi#3838)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/gpt-apply-patch/extension.ts`: on a non-GPT model with no in-memory record of removed edit tools, an active `apply_patch` restores the registered `edit` and `write`.

### Why

- A reloaded, resumed or restarted session kept `apply_patch` active from its GPT period, while the new extension instance had forgotten which edit tools it replaced, so switching to Claude left no editing tool.

### Why an extension could not handle it

- The fix is inside the builtin extension that owns the swap.

### Expected merge conflict zones

- LOW: the non-GPT branch of `syncToolset` in `extension.ts`.
