### Fixed
- After a session moves, its old owner's late loop-hook call no longer runs the user's hooks (senpi#5916). The hand admits an epoch-bearing hook call only through the tool scope's epoch fence and answers a refusal with `hook.refused {callId, reason, epoch, floor}` (`floor_missing`, `epoch_fenced` or `callId_taken`; never recorded as an answer). A known call is replayed before the fence, but only to the sender that presented it or the scope's owner. `serveLoopHooks` gains `ownerOf` and `records`; a record started by another process answers `hook.restarted`. The loop host's `epoch` option is now `() => number`, read at each transmission; a refusal echoing an older epoch re-issues the same call once per epoch, and other refusals reject `LoopHookRefusedError`.

## 2026-11-05 - Epoch fence on the loop-hook lane (senpi#5916)

### What changed

- `packages/agent/src/execution/loop-hook-host-protocol.ts`: `hook.call` carries an optional `epoch`; new `hook.refused` and `hook.restarted` messages with total decoders.
- `packages/agent/src/execution/loop-hook-host-hand.ts`: fence check against the tool scope's floor, sender-keyed replay before the fence, `callId_taken`, refusals never recorded, `hook.restarted` for records started by another process; options `fence`, `sender`, `ownerOf`, `records`.
- `packages/agent/src/execution/loop-hook-host.ts`: `epoch: () => number` stamped per transmission, one re-issue per epoch on a stale refusal, `LoopHookRefusedError`, `hook.restarted` handling.
- `packages/agent/src/execution/remote-epoch.ts`: `HandEpochFence.floorOf(scope)`.
- `packages/agent/src/index.ts`: exports `LoopHookRefusedError`, `LoopHookRecord` and `LoopHookRefusal`.

### Why

S35 fenced the tool lanes only; the loop-hook lane had no epoch and no floor check, so after a move the old owner's late hook call ran the user's hooks (senpi#5916, found by the hosted-hooks design review).

### Why an extension could not handle it

The check must run on the hand's own hook lane before any hook starts, with the same fence the tool lanes use.

### Expected merge conflict zones

`loop-hook-host-hand.ts` `serve`; `loop-hook-host.ts` frame dispatch and `send`; `loop-hook-host-protocol.ts` decoder; `remote-epoch.ts` fence interface; `src/index.ts` exports.
