## 2026-10-31 - Extension event placement for a runtime without a session (senpi#5250)

### What changed

- `packages/coding-agent/src/core/extensions/runner.ts`: exported `EXTENSION_EVENT_PLACEMENT` (`runtime` / `loop` / `split` for every `ExtensionEvent["type"]`, compile-checked exhaustive) and `ExtensionEventPlacement`; `emit()` returns without dispatching a `loop` event when the runner has no session manager.

### Why

- A runtime with no session (brain/hand split, senpi#5231) delivers its own events and must not run loop handlers it has no loop for.

### Why an extension could not handle it

- Event dispatch is the runner's; an extension cannot stop the runner from calling other extensions' handlers.

### Expected merge conflict zones

- LOW: the type block after `RunnerEmitEvent` and the first lines of `emit()` in `packages/coding-agent/src/core/extensions/runner.ts`.
