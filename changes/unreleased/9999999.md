## Test: the registry preflight tests set their own ref

**What:** `scripts/registry-preflight.test.mjs` no longer lets the runner's `GITHUB_ACTIONS`/`GITHUB_REF` leak into the spawned `release.mjs`/`publish.mjs`: the stub env strips both, and every case sets the pair it means (a live run from `refs/heads/main` for the preflight cases, and a new case that proves a `refs/pull/<n>/merge` dispatch is refused before the suite, any tag or any push).

**Why:** the two `release.mjs registry preflight` cases inherited the CI job's ref, so on every pull-request run the ref guard stopped `release.mjs` before the registry preflight they test (`#6690`).

**Breaking:** none (test-only).
