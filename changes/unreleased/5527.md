## 2026-11-02 - No extended-keys hint when the multiplexer does not register the option (code-yeongyu/oh-my-openagent#10373, PR #5527)

### What changed

- `packages/coding-agent/src/modes/interactive/tmux-setup.ts`: `buildTmuxSetupWarning` skips the `set -g extended-keys on` recommendation when `tmux show -gv extended-keys` read back an empty value. `off` and any other non-empty value still warn.

### Why

- Real tmux always prints `on`, `off` or `always` for `extended-keys`. A tmux-compatible multiplexer without that option (psmux 3.4) exits 0 with an empty value, so the recommendation could never be satisfied and the startup warning never cleared.

### Why an extension could not handle it

- The tmux setup warning is built and shown by interactive mode at startup; no extension hook can change its recommendations.

### Expected merge conflict zones

- LOW: the extended-keys condition at the top of `buildTmuxSetupWarning`.
