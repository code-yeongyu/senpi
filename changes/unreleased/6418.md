## 2026-11-11 - session_status keeps a stable lastChange.at for sessions that never changed (senpi#6418)

### What changed

- `src/modes/rpc/session-status-stream.ts`: `lastChangeOf` records the first `open` stamp it builds for a session with no recorded change and returns it from then on; a published change still replaces it.

### Why

- Every subscription snapshot stamped idle sessions with the subscribe time, so each resubscribe looked like activity (senpi#6415).

### Why an extension could not handle it

- The stamp is built inside the host's session status stream.

### Expected merge conflict zones

- LOW: `lastChangeOf` in `session-status-stream.ts`.

### Fixed
- `session_status` no longer reports idle sessions as just changed on every new subscription; `lastChange.at` stays stable until a real change ([#6418](https://github.com/code-yeongyu/senpi/pull/6418))
