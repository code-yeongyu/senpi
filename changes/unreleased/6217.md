## 2026-11-08 - A `move_session` copy id ending in a separator is refused before anything is written (senpi#5930)

### What changed

- `packages/coding-agent/src/modes/rpc/session-move-request.ts`: `parseCopy` now applies `assertValidSessionId` (the rule `forkFrom` applies) in addition to `isPlainId`, so a `sessionId` ending in `.`, `_` or `-` is refused with `invalid_move_request` before anything is written.

### Why

- The parser accepted `copy-` or `a.`, and the id then failed inside `forkFrom` as `move_failed` — the wrong code, after the target folder had already been created.

### Why an extension could not handle it

- Request parsing and the `move_session` wire codes live in the RPC core; no extension runs before a request is parsed.

### Expected merge conflict zones

- LOW: the `parseCopy` validation lines.

## 2026-11-08 - `move_session` copy refuses ids named by inherited ownership entries, and `forkFrom` validates before creating its folder (senpi#5930)

### What changed

- `packages/coding-agent/src/core/session-move/copy.ts`: `copySessionAs` now also refuses any id named by a `session_id` of an ownership entry the source inherited (via the new `ownershipSessionIds` helper in `packages/coding-agent/src/core/session-move/ownership.ts`), with `invalid_move_request`.
- `packages/coding-agent/src/core/session-manager.ts`: `forkFrom` validates `options.id` with `assertValidSessionId` before creating the target folder, instead of after.

### Why

- A copy made under an id named by an inherited ownership entry answered `success: true` but refused every write, because those entries applied again under that id — breaking the "the copy is writable" claim. Only the source's own header id was refused before.
- A trailing-separator id left an empty session folder behind, because the folder was created before the id check ran.

### Why an extension could not handle it

- Session copying, ownership folding and fork identity live in the session core; no extension runs inside them.

### Expected merge conflict zones

- LOW: the refusal checks in `copySessionAs`, the `forkFrom` validation order, and the new `ownershipSessionIds` helper.
