## 2026-11-26 - Identity reads at tool dispatch (senpi#7528)

### What changed

- `packages/coding-agent/src/core/tool-dispatch/tool-child-runtime.ts` supplies the session cwd to `packages/coding-agent/src/core/tool-dispatch/tool-dispatcher.ts`, which checks for literal identity reads before placement and masks matching JSON fields in tool results and updates.

### Why

- Tool calls could read identity files and return their contents to the model. A filename mention, a `.key` expression, or a generic object-storage key is not an identity read.

### Why an extension could not handle it

- The check must apply to both tool placements even in a session with extensions disabled.

### Expected merge conflict zones

- The dispatcher's `run` method, constructors and factory options; the runtime's construction of the dispatcher.
