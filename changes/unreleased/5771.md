### Added
- `createAgentSession({ executionPipelineWitness })`: a session's execution-pipeline receipts go to the sink it is given, never into its entries. Without one, `SENPI_EXECUTION_PIPELINE_WITNESS=<path>` appends one JSON line `{ pipeline, toolCallId }` per call to that file ([#5771](https://github.com/code-yeongyu/senpi/pull/5771)).

<!-- changes-log: packages/coding-agent/src/core/changes.md -->
- `packages/coding-agent/src/core/execution/pipeline-witness-sink.ts`: `resolveWitnessSink()` picks the configured sink, else a file sink for `SENPI_EXECUTION_PIPELINE_WITNESS`, else none; `sdk.ts` passes it to the agent as `onExecutionPipeline`. The EQ runner reads its witness from that per-run file.
