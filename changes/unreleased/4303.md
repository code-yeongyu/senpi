## 2026-10-26 - A full disk during a turn is a typed, actionable error (senpi#4295)

### What changed

- `packages/coding-agent/src/core/session-disk-full.ts` (new): `SessionDiskFullError` (`errorCause: "disk_full"`, the system `code` kept, `path`, `neededBytes`) with the message `Disk full: the session could not be saved because the disk is full (<file> needed <n>). Free disk space, then continue this session.` Free space is not probed, because the session path admits no new blocking filesystem call. `sessionWriteError` converts an `ENOSPC`/`EDQUOT` write error and leaves every other error unchanged.
- `packages/coding-agent/src/core/session-manager.ts`: `_persist` converts a refused append and a refused first flush, with the bytes that write needed.
- `packages/coding-agent/src/core/agent-session.ts`: `transcript_write_failed` carries `errorCause: "disk_full"` and `diskFull` details for that error. The prompt rejects with the typed error.

### Why

- A full disk mid-turn surfaced as the raw `ENOSPC: no space left on device, write`. The actionable text existed only in the interactive crash handler, so RPC and desktop users never learned what to do.

### Why an extension could not handle it

- The error is raised inside `SessionManager._persist` and reported from the message-end write in `AgentSession`, before any extension sees it.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/core/session-manager.ts`, the append and first-flush `catch` blocks in `_persist`; the `transcript_write_failed` union member and its `_emit` in `agent-session.ts`.

## 2026-10-26 - Show the disk-full error as it is (senpi#4295)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: a `transcript_write_failed` with `errorCause: "disk_full"` is shown as an error with its actionable message, instead of the generic not-saved warning built from the error code.

### Why

- The person must see that the disk is full and what to do, not `(ENOSPC)`.

### Why an extension could not handle it

- The session event switch is core interactive-mode code.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/modes/interactive/interactive-mode.ts`, the `transcript_write_failed` case.

## 2026-10-26 - Disk-full prompt rejections carry an error code (senpi#4295)

### What changed

- `packages/coding-agent/src/modes/rpc/client-input-handler.ts`: a prompt rejected by a full disk responds with `errorCode: "disk_full"` and `errorData` (`path`, `neededBytes`).

### Why

- RPC clients need a machine-readable cause to show the person an actionable disk-full message.

### Why an extension could not handle it

- The prompt response is built inside the RPC client input handler.

### Expected merge conflict zones

- LOW: `packages/coding-agent/src/modes/rpc/client-input-handler.ts`, the failure response spread.
