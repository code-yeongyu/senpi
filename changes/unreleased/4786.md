## 2026-10-29 - Bundled Claude Agent SDK 0.3.312 (senpi#3789)

### What changed

- `packages/coding-agent/package.json`: `@anthropic-ai/claude-agent-sdk` 0.3.306 -> 0.3.312; `bun.lock`, `package-lock.json` and `install-lock/` regenerated by the repo's lock scripts (`npm run refresh-lock`, `node scripts/generate-coding-agent-install-lock.mjs`, `node scripts/generate-claude-agent-sdk-platform-lock.mjs`).

### Why

- The Releasability gate's SDK currency check fails on main once a newer SDK is published; the anthropic-subscription lane needs the current SDK to use new Claude models.

### Why an extension could not handle it

- The SDK is a pinned dependency of the coding-agent package.

### Expected merge conflict zones

- The single dependency line in `packages/coding-agent/package.json`, `bun.lock`, `package-lock.json` and `install-lock/package-lock.json`.

## 2026-10-29 - Advertised [CC] floor 2.1.312 (senpi#3789)

### What changed

- `packages/ai/src/api/anthropic-messages.ts`: `claudeCodeVersion` moves 2.1.306 -> 2.1.312 to match the @anthropic-ai/claude-agent-sdk 0.3.312 bump in `packages/coding-agent/package.json`.

### Why

- The floor must track the pinned SDK's shipped [CC] version (senpi#2033); the SDK currency gate failed on main once 0.3.312 was published.

### Why an extension could not handle it

- The advertised [CC] identity is a build-time constant; it is not runtime extension surface.

### Expected merge conflict zones

- The single `claudeCodeVersion` declaration line.
