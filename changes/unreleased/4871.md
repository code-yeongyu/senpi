## 2026-10-29 - Model candidates use their own compaction budgets (senpi#3977)

### What changed

- `packages/coding-agent/src/core/agent-session.ts`: resolve compaction settings for the candidate in model admission, cycling, deferred-switch and fallback-fit projections. Compare source and target usable windows with each model's own settings.

### Why

- `packages/coding-agent/src/core/agent-session.ts`: a source model's large per-model reserve was charged to smaller candidates, rejecting even empty sessions with an impossible requirement (#3977, #3636).

### Why an extension could not handle it

- `packages/coding-agent/src/core/agent-session.ts`: these core admission checks run before a model switch can reach extension hooks.

### Expected merge conflict zones

- `packages/coding-agent/src/core/agent-session.ts`: compaction settings arguments in candidate projections; the measured-usage repair logic from #4418 is unchanged.
