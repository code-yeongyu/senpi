## 2026-11-22 - Identify ignored skills by their declared name

### What changed

- `packages/coding-agent/src/core/package-manager.ts` records the discovery authority for each ignored skill path.
- `packages/coding-agent/src/core/resource-loader.ts` passes that authority to the ignored-skill diagnostic.
- `packages/coding-agent/src/core/skill-access.ts` supports a bounded prefix read using the checked descriptor.
- `packages/coding-agent/src/core/skills.ts` compares the declared name to loaded skill names. If the name is unknown, discovery keeps the warning.

### Why

- A directory name can differ from the skill name, causing a missing warning for one skill or a misleading warning for one already loaded.

### Why an extension could not handle it

- The builtin resource loader owns ignore-file discovery and supplies the diagnostic to clients.

### Expected merge conflict zones

- Skill discovery provenance and the checked file reader are shared with normal skill loading.
