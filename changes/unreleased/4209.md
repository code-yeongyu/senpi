## 2026-10-24 - Reject duplicate Anthropic API keys (senpi#4209)

### What changed

- `packages/ai/src/models.ts`: reject an existing regular Anthropic API key inside the serialized credential mutation, preserving slots and metadata.

### Why

- `packages/ai/src/models.ts`: repeated login should report an already-added key instead of creating a duplicate account.

### Why an extension could not handle it

- `packages/ai/src/models.ts`: native login owns the credential mutation and must compare against the latest serialized state.

### Expected merge conflict zones

- `packages/ai/src/models.ts`: the API-key branch of `loginProvider`.

## 2026-10-24 - Manage native Anthropic API accounts interactively (senpi#4209)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/account/index.ts`: add the Anthropic account picker, pin/unpin, rename, confirmed removal and argument completions.
- `packages/coding-agent/src/core/extensions/builtin/account-display-name.ts`: share the optional visible-name helper with regular Anthropic API accounts.

### Why

- `packages/coding-agent/src/core/extensions/builtin/account/index.ts`: native API accounts need discoverable management without memorizing slot IDs.
- `packages/coding-agent/src/core/extensions/builtin/account-display-name.ts`: API accounts should use the same visible-name convention as subscription accounts without changing stable IDs.

### Why an extension could not handle it

- `packages/coding-agent/src/core/extensions/builtin/account/index.ts`: the native account command owns the credential mutations and completion surface.
- `packages/coding-agent/src/core/extensions/builtin/account-display-name.ts`: the shared native login naming helper must accept the regular provider directly.

### Expected merge conflict zones

- `packages/coding-agent/src/core/extensions/builtin/account/index.ts`: command registration, Anthropic picker and completion branches; preserve reset and unused-account behavior.
- `packages/coding-agent/src/core/extensions/builtin/account-display-name.ts`: the provider guard in `maybeNameNewSubscriptionAccount`.
