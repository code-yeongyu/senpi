## 2026-11-22 - First-party Mythos models default to native tool search (senpi#7257)

### What changed

- `packages/ai/src/utils/prompt-cache-ttl.ts`: the default tool-search gate also accepts versioned `claude-mythos-*` ids and the exact `claude-mythos-preview` alias on the first-party `anthropic` provider. Kept in lockstep with the coding-agent native tool-search gate.

### Why

- Anthropic lists tool search for the Mythos line, but the default matched only `opus|sonnet|fable`, so Mythos sessions ran without native tool search unless a compat override was set.

### Why an extension could not handle it

- This is the shared default that every caller reads; an extension can set a per-model override but cannot correct the default for all sessions.

### Expected merge conflict zones

- LOW: the model-id match in the default gate.
