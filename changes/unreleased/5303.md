## 2026-11-01 - Override the MCP SDK's vulnerable transitive dependencies (senpi#4820)

### What changed

- `package.json`: root `overrides` add `body-parser` 2.4.0 and move `qs` 6.16.0 -> 6.16.2, `fast-uri` 3.1.8 -> 3.1.9, `ip-address` 10.7.2 -> 10.7.5; `package-lock.json` and `bun.lock` regenerated with `npm run refresh-lock`.

### Why

- The scheduled `npm audit --omit=dev` job fails on these four packages, all reached through `@modelcontextprotocol/sdk` (express, express-rate-limit) and ajv. Each new version is inside its parent's declared range.

### Why an extension could not handle it

- Dependency resolution happens at install time, before any extension loads.

### Expected merge conflict zones

- LOW: the root `overrides` block and the lockfile entries for these four packages.
