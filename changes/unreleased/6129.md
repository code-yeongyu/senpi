## 2026-11-06 - Session listing skips files that vanish mid-list; listDir fails when its directory is removed (senpi#5621)

### What changed

- `packages/agent/src/harness/session/jsonl/repo.ts`: `readSessionMetadata` skips a session file whose header read fails with `not_found` (deleted or renamed after `listDir` returned it); any other read error still fails the listing.
- `packages/agent/src/harness/env/nodejs.ts`: `listDir` re-checks the listed directory when an entry was skipped as missing, so a directory removed mid-call fails with `not_found` instead of silently returning a partial list.
- `packages/agent/src/harness/types.ts`: documents the `listDir` race contract on `FileSystem.listDir`.

### Why

A session file can disappear between listing and reading (the same race as #5272, one step later), and a directory can disappear mid-list so every remaining `lstat` reports ENOENT; the first failure aborted the whole listing and the second silently returned a partial list.

### Why an extension could not handle it

Session listing and the Node filesystem adapter are harness internals; no extension point wraps `JsonlSessionRepo` listing or `NodeExecutionEnv.listDir`.

### Expected merge conflict zones

- LOW: `packages/agent/src/harness/session/jsonl/repo.ts` `readSessionMetadata`; `packages/agent/src/harness/env/nodejs.ts` `listDir`.
