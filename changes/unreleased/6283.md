## 2026-11-09 - A required question answered only in part refuses the gated action (senpi#2966)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/ask-user/format.ts`: `formatBody` now routes a required call to the gated branch whenever any question is unanswered, including settlements of `answered` and `comment-submitted`. `formatGatedNoAnswer` renders the partial case as "The user answered only part of the question.", the answered lines as real answers, an `Unanswered:` line naming the unanswered questions, and the partial-specific refusal "The unanswered question still gates the action: do not take the action it gates until it is answered. Keep that action pending and end the turn.". A comment-only reply to a required question still gates, but its reason line says "The user left a comment without answering the question." and the comment itself survives in the rendering and in `words`, exactly as the non-gated `comment-submitted` branch renders it. A fully answered required call and all non-required renderings are unchanged.

### Why

- A required multi-question call that settled as `answered` with some questions still in `unanswered` read as an ordinary partial answer, with no instruction to hold the gated action, so the model could act on a question the user never answered (senpi#2966).

### Why an extension could not handle it

- The answer text is rendered by the ask-user builtin itself before the model sees the tool result; no extension hook rewrites tool-result text after formatting.

### Expected merge conflict zones

- LOW: the gated-branch condition in `formatBody` and the partial-answer branch in `formatGatedNoAnswer`.
