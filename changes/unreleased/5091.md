## 2026-10-30 - Anthropic message conversion exported as `toAnthropicMessageParams` (senpi#5091)

### What changed

- `packages/ai/src/api/anthropic-messages.ts`: new exported pure `toAnthropicMessageParams(messages, model, options)` = the request path's `transformMessages` + `normalizeToolCallId` step (extracted as `transformAnthropicMessages`, which `buildParams` now calls) followed by the same `convertMessages`, with no cache breakpoints. `convertMessages` also returns `assistantSources` (param index -> the transformed assistant message it came from); `buildParams` ignores it.

### Why

- `packages/ai/src/api/anthropic-messages.ts`: the anthropic-subscription cold seed replays history as a native Claude Code transcript (senpi#1977, #3231) and must apply exactly the Anthropic rules (tool-call id normalization and pairing, signed-thinking replay, tool-result images) instead of re-deriving them.

### Why an extension could not handle it

- `packages/ai/src/api/anthropic-messages.ts`: `convertMessages` and its helpers are module-private; re-implementing them in the extension would fork the mapping.

### Expected merge conflict zones

- LOW: `buildParams`'s `transformMessages` call, the `ConvertedAnthropicMessages` interface and the two `return { messages: params, ... }` lines of `convertMessages`.

## 2026-10-30 - Seeded Claude Code transcript builder, not wired yet (senpi#5091)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/history-transcript.ts` (new): `buildSeedTranscript` turns a senpi history (minus a final user message) into Claude Code transcript chain entries via `toAnthropicMessageParams`, with SDK tool names, deterministic content-chained uuids, `assistantUuidByIndex` keyed like the session binding, `payloadBytes`, and one optional tail `cache_control`. `writeSeedTranscript` writes them to `<config root>/projects/<project>/<session>.jsonl` (temporary file + rename, 0600); `claudeProjectDirName` mirrors the CLI's project-key rule including its long-path hash.
- `packages/coding-agent/test/anthropic-subscription-seed-transcript.test.ts` (new): writes a 3-turn history and reads it back with the SDK's `getSessionMessages`.

### Why

- Step 1 of the native-frame cold seed (senpi#1977, image half of #3231): a seeded transcript plus `resume` replays history natively, where the flattened `<conversation_history>` envelope loses tool structure, misses the cache and surfaces tool images as user attachments.

### Why an extension could not handle it

- It is extension code; this entry records the new module for the extension's tracker.

### Expected merge conflict zones

- NONE: new files only; no live path imports `history-transcript.ts` yet.
