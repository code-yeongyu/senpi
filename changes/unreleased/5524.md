## 2026-11-02 - Main-screen mouse tracking enables in a herdr pane on Windows (senpi#3353)

### What changed

- `packages/tui/src/tui-main-screen.ts`: `applyMouseTracking` counts a win32 terminal as mouse-capable when `HERDR_ENV === "1"` as well as when `WT_SESSION` is set. A plain console (neither variable) and Termux stay excluded.

### Why

- A herdr pane on Windows is not Windows Terminal and sets no `WT_SESSION`, so the mouse-enable sequence was never written there, even with `terminal.mouse: "always"`, and pending-question blocks could not be clicked.

### Why an extension could not handle it

- The capability gate runs inside the TUI renderer before any coding-agent extension can write terminal modes.

### Expected merge conflict zones

- LOW: `applyMouseTracking` in `packages/tui/src/tui-main-screen.ts`.
