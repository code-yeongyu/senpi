### Fixed
- On Windows, ending a pipe-fallback terminal session no longer uses `taskkill /T`, which could also kill an unrelated older process whose recorded parent pid had been recycled; it ends the owned process and its creation-time-checked descendants by explicit pid ([#4053](https://github.com/code-yeongyu/senpi/issues/4053))
