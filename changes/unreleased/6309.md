## 2026-11-10 - Claude Fable 5.2 is a released model (senpi#3893)

### What changed

- `packages/ai/scripts/generate-models.ts`: no longer imports `src/utils/fable55-launch.ts`. `ANTHROPIC_ALLOWED_FALLBACK_MODELS` names `claude-fable-5-2` (Opus 4.8 / Opus 5, the published refusal-fallback targets) in place of the provisional launch id. The Fable/Mythos mid-conversation effort and system/tool-change patterns match `5-2` / `5.2`. The adaptive-only and adaptive-thinking predicates name the `mythos-5` family in place of the provisional id.
- `src/providers/data/`: strict regeneration. `claude-fable-5-2` lands in anthropic, amazon-bedrock (`anthropic.`, `us.`, `global.`), openrouter, vercel-ai-gateway, opencode and venice with the models.dev price and limits and the same compat set as Fable 5.1. The same run carries current upstream drift (openrouter, opencode, opencode-go, bedrock, vercel, google, opengateway rows and prices).

### Why

- The provisional `claude-fable-5-5` launch shipped on 2026-11-09 as Claude Fable 5.2. The launch block's provisional id no longer names a real model, so the generator routes the released id directly.

### Why an extension could not handle it

- Catalog generation runs before any extension loads; the generator's per-model compat and fallback tables are the only place these facts live.

### Expected merge conflict zones

- MEDIUM: `ANTHROPIC_ALLOWED_FALLBACK_MODELS` and the Anthropic compat predicates in `generate-models.ts`; LOW: the regenerated `src/providers/data/*.json` snapshots.

## 2026-11-10 - Bundled Claude Agent SDK 0.3.321 (senpi#3893)

### What changed

- `packages/coding-agent/package.json`: `@anthropic-ai/claude-agent-sdk` 0.3.306 -> 0.3.321. `bun.lock`, `package-lock.json`, `install-lock/` and the SDK platform lock are regenerated with the repository scripts.

### Why

- Claude Code 2.1.321, bundled by SDK 0.3.321, is the first build whose model table knows `claude-fable-5-2` / `claude-mythos-5-2`. The omo#8700 regression requires the bundled Claude Code to embed every Claude model senpi promotes.

### Why an extension could not handle it

- The SDK is a pinned dependency of the coding-agent package.

### Expected merge conflict zones

- The single dependency line in `packages/coding-agent/package.json`, `bun.lock`, `package-lock.json` and `install-lock/package-lock.json`.

## 2026-11-10 - Cursor capability row for Claude Fable 5.2 (senpi#3893)

### What changed

- `packages/ai/src/cursor/capability-table.ts`: `claude-fable-5-2` takes the same served shape as `claude-fable-5-1` (300k default context, 1M max, thinking/context/effort parameters, low..max levels) until a live AvailableModels capture lists it.
