## 2026-11-22 - Help flags cache catches same-tick edits (senpi#7306)

### What changed

- `packages/coding-agent/src/cli/help-flags-cache.ts`: input stamps carry inode and ctime, and an input changed within 2 s of the cache write also stores a content digest that the read verifies.

### Why

- On coarse-timestamp filesystems a same-size edit or a new extension within the cached tick left `--help` showing stale extension flags (senpi#4561).

### Why an extension could not handle it

- The help fast path runs before extensions load.

### Expected merge conflict zones

- LOW: `stamp`, `readHelpFlagsCache` and `writeHelpFlagsCache` in `help-flags-cache.ts`.
