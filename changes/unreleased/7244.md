## 2026-11-22 - Admit automated prompts after a wider model restores capacity (#2073)

### What changed

`packages/coding-agent/src/core/agent-session.ts` records the effective admission budget when failed compaction blocks future prompts. At admission it can release that block after a verified budget increase if the content fits.

### Why

`packages/coding-agent/src/core/agent-session.ts` compared only the content size. Reverting to a wider model did not shrink the transcript, so unattended turns could stay blocked indefinitely.

### Why an extension could not handle it

`packages/coding-agent/src/core/agent-session.ts` owns the gate before it dispatches the request. An extension cannot release that internal state or establish the budget used when it armed.

### Expected merge conflict zones

`packages/coding-agent/src/core/agent-session.ts`: blocked-admission state, the two failure paths that arm it, and the admission-time release predicate.
