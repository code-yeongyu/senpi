## 2026-11-14 - Honor exact native PTY child environments

### What changed

- `crates/senpi-pty/src/lib.rs` retains whether an environment was supplied, and `crates/senpi-pty/src/session.rs` clears inherited variables before applying that environment.
- The native PTY regression exercises omitted, empty, deleted, and explicit environment values through a real child.

### Why

- An omitted entry in a supplied environment could leak the native parent's value into a shell child, including engine-only TLS settings.

### Why an extension could not handle it

- The inherited environment was reintroduced inside the native PTY process builder after the caller constructed its environment.

### Expected merge conflict zones

- LOW: native session option conversion and command construction.
