## 2026-11-23 - Use the compact GPT-6 prompt core for Astra

### What changed

- GPT-6 Astra keeps its preset name and renders the existing GPT-6.2 read-first core. The runtime does not append a separate todo block on either preset.

### Why

- A single core keeps the two GPT-6 presets aligned and lets Astra spend less context on repeated instructions. The model reads and reasons first while honoring user- and workflow-requested delegation.

### Why an extension could not handle it

- This is the built-in preset's renderer and todo-ownership contract; an extra extension would inject another layer of instructions.

### Expected merge conflict zones

- LOW: GPT-6 Astra preset selection and `contract.ts`.
