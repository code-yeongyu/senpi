## 2026-11-22 - Inherit a known context window for proxy and configured models (#3824)

### What changed

`packages/coding-agent/src/core/model-config-schema.ts` accepts discovered context metadata separately from explicit config. `packages/coding-agent/src/core/model-discovery.ts` extracts valid limits; `packages/coding-agent/src/core/provider-composer.ts` applies the precedence rules; `packages/coding-agent/src/core/model-runtime.ts` supplies exact catalog matches and unknown-size warnings.

### Why

`packages/coding-agent/src/core/provider-composer.ts` replaced omitted windows with 128k even when metadata was available. `packages/coding-agent/src/core/model-discovery.ts` discarded advertised limits, and `packages/coding-agent/src/core/model-runtime.ts` gave no warning.

### Why an extension could not handle it

`packages/coding-agent/src/core/model-config-schema.ts`, `packages/coding-agent/src/core/model-discovery.ts`, `packages/coding-agent/src/core/provider-composer.ts` and `packages/coding-agent/src/core/model-runtime.ts` own config parsing, discovery, composition and the built-in model snapshot before an extension sees a selected model.

### Expected merge conflict zones

Model definition fields in `packages/coding-agent/src/core/model-config-schema.ts`; listing merge in `packages/coding-agent/src/core/model-discovery.ts`; custom model construction in `packages/coding-agent/src/core/provider-composer.ts`; composition and warnings in `packages/coding-agent/src/core/model-runtime.ts`.
