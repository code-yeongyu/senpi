## 2026-11-22 - Preserve durable file monitor age on restore (senpi#2968)

### What changed
- `packages/coding-agent/src/core/extensions/builtin/terminal/durable-file.ts` passes the manifest creation time when restoring a durable watch.
- `packages/coding-agent/src/core/extensions/builtin/terminal/file-monitor-record.ts` uses it as the restored record's start time.

### Why
- The footer derives elapsed time from the live record. Using the restore time discarded the watch's age before restart.

### Why an extension could not handle it
- The terminal builtin owns the manifest restore and the record read by status consumers.

### Expected merge conflict zones
- File-watch registration options and the checkpointed-file restore handler.
